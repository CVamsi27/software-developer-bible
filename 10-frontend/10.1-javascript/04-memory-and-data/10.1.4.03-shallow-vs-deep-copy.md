# Shallow vs Deep Copy

Understanding the difference between shallow and deep copying is fundamental to writing predictable code that avoids unintended mutation. JavaScript provides several mechanisms, each with distinct behavior and performance characteristics.

## Definition

| Copy Type | Definition | Nested Structure Sharing | Top-Level Identity |
| :------------------------ | :------------------------ | :------------------------ | :------------------------ |
| **Shallow Copy** | Creates a new top-level object; nested objects are shared by reference | Shallow: nested refs shared | New top-level container |
| **Deep Copy** | Creates a new object; all nested structures recursively copied | Deep: no shared references | New recursive structure |

> **Textbook Definition:** A shallow copy constructs a new object and copies the values of top-level properties. If a property is an object, the copy retains a reference to the original object rather than creating a independent clone. A deep copy recursively copies all nested structures, producing a completely independent duplicate.

## First Principles

1. **Value vs. Reference:** Primitive values are copied by value; object values are copied by reference. A shallow copy duplicates the top-level container but preserves references to nested objects.

2. **Identity Preservation:** When copying an object, the copy's top-level properties point to the same memory locations as the original for nested objects. Mutating a nested property through the copy affects the original.

3. **Recursion Requirement for Independence:** Deep copying requires recursively traversing the entire object graph, creating new instances for each nested structure, and handling special types (Date, Map, Set, etc.) appropriately.

4. **Circular Reference Risk:** Objects can contain references to themselves or create cycles. Deep copying must track visited objects to avoid infinite recursion.

## Shallow Copy Mechanisms

### 1. Object Spread (`...`)

```javascript
const original = { a: 1, b: { c: 2 } };
const shallow = { ...original };

console.log(shallow.a); // 1
console.log(shallow.b === original.b); // true — nested object shared!
shallow.b.d = 3;
console.log(original.b.d); // 3 — mutation propagates!
```

### 2. `Object.assign()`

```javascript
const original = { a: 1, b: { c: 2 } };
const shallow = Object.assign({}, original);

shallow.a = 10;
console.log(original.a); // 1 — top-level unaffected
shallow.b.c = 20;
console.log(original.b.c); // 20 — nested mutation propagates
```

### 3. `Array.prototype.slice()`

```javascript
const original = [1, 2, { a: 3 }];
const shallow = original.slice();

console.log(shallow === original); // false
console.log(shallow[2] === original[2]); // true — nested object shared
shallow[2].b = 4;
console.log(original[2].b); // 4 — mutation propagates
```

### 4. `Array.prototype.concat()`

```javascript
const original = [1, [2, 3]];
const shallow = original.concat();

shallow[1][0] = 99;
console.log(original[1][0]); // 99 — nested mutation propagates
```

## Deep Copy Mechanisms

### 1. JSON `parse`/`stringify` (Limited)

```javascript
const original = { a: 1, b: { c: 2 }, d: [3, 4] };
const deep = JSON.parse(JSON.stringify(original));

deep.b.c = 99;
console.log(original.b.c); // 2 — deeply independent!

// Limitations: functions, undefined, Symbol, and circular references throw
// const withLoop = {}; withLoop.self = withLoop; // JSON.parse(JSON.stringify(withLoop)) throws
```

### 2. Recursive Function (Handles Objects + Arrays)

```javascript
function deepCopy(obj, visited = new WeakMap()) {
  // Handle primitive values
  if (typeof obj !== 'object' || obj === null) return obj;

  // Handle circular references via visited set
  if (visited.has(obj)) return visited.get(obj);

  // Initialize constructor-dependent result
  const constructor = obj.constructor;
  const copy = constructor === Array ? [] : constructor === Date ? new Date(obj) : {};

  visited.set(obj, copy);

  // Recursively copy own properties
  for (let key of Object.keys(obj)) {
    copy[key] = deepCopy(obj[key], visited);
  }

  return copy;
}

const original = { a: 1, b: { c: 2 } };
const deep = deepCopy(original);
deep.b.c = 99;
console.log(original.b.c); // 2 — fully independent
```

### 3. `structuredClone()` (ES2022, Recommended)

```javascript
const original = { a: 1, b: { c: 2 }, d: new Date('2024-01-01') };
const deep = structuredClone(original);

deep.b.c = 99;
console.log(original.b.c); // 2 — fully independent

// Preserves types that JSON cannot: Date, Map, Set, Blob, File, etc.
const withSet = structuredClone(new Set([1, 2, 3]));
console.log(withSet instanceof Set); // true
```

## Comparison: Shallow vs Deep Copy Trade-offs

| Criterion | Shallow Copy | Deep Copy |
| :------------------------ | :------------------------ | :------------------------ |
| **Performance** | O(n) — copies top-level only | O(n + m + ...) — recursive copy |
| **Memory Usage** | Low — shares nested refs | Higher — allocates new nested structures |
| **Mutation Isolation** | Nested mutations propagate | Fully isolated — no propagation |
| **Circular Reference Handling** | Naturally handles (shares) | Requires visited-set tracking |
| **Type Preservation** | Top-level type preserved | `structuredClone()` preserves most types |
| **API Availability** | Built-in (`...`, `Object.assign`, `.slice()`) | Manual recursion or `structuredClone()` |

## When to Use Which

| Scenario | Recommended Approach |
| :------------------------ | :------------------------ |
| Passing data to a function without risk | Shallow copy (spread `...`) |
| Caching with independent state | Deep copy (`structuredClone()`) |
| Preserving form state in React/Vue | Deep copy for complex forms |
| Simple object merging | Shallow `Object.assign()` or spread |
| Structured cloning with functions/Symbols | `structuredClone()` |
| Performance-critical inner loops | Shallow copy (avoid recursion overhead) |

## Memory Leak Prevention

Shallow copies can inadvertently retain references, preventing garbage collection of original objects when no other strong references exist. Deep copying (or using `structuredClone()`) ensures the original can be GC'd if the copy is the only remaining reference — though this depends on whether the deep copy itself retains references.

```javascript
// Shallow: original object NOT GC'd if copy holds nested ref
const obj = { nested: { data: heavy } };
const copy = { ...obj };
obj = null; // original still reachable via copy.nested

// Deep: original GC'd when copy is the only ref
const obj2 = { nested: { data: heavy } };
const deep = structuredClone(obj2);
obj2 = null; // original GC'd (deep has independent nested structure)
```

## Summary

- **Shallow copy**: New top-level container; nested references shared with original. Fast but mutation propagates.
- **Deep copy**: Recursively independent structure; no shared references. Fully isolated but slower and more memory-intensive.
- **`structuredClone()`**: ES2022 recommended API; handles Objects, Arrays, Maps, Sets, Date, Blob, File, and more; avoids JSON limitations.

Choose shallow for performance-critical code where top-level isolation suffices. Use deep copy or `structuredClone()` when complete mutation isolation is required.

# Recent ECMAScript Features (ES2022–ES2026)

A report needs a sorted copy of its rows, groups by team, and a way to consume pages as they arrive. New built-ins can simplify each step, but their names do not tell you whether they copy data, preserve identity, collect everything, or depend on a host API. Choose by behavior first; use edition and runtime support as compatibility checks.

```js
const rows = [{ name: 'b', team: 2 }, { name: 'a', team: 1 }];

const sorted = rows.toSorted((x, y) => x.name.localeCompare(y.name));
console.log(rows === sorted); // false — new outer array, same row objects

const byTeam = Map.groupBy(sorted, row => row.team);
console.log(byTeam.get(1)); // [{ name: 'a', team: 1 }]
```

## Definition

An ECMAScript edition is a dated revision of the language standard. It specifies syntax and built-in behavior; it does not guarantee that a particular browser, server runtime, or TypeScript target supports every addition.

> **Textbook Definition:** An ECMAScript edition is a published version of ECMA-262 that defines the language grammar, runtime semantics, and standard built-in objects for that edition. Host APIs and implementation support are specified separately.

## First Principles

A new method is useful only when its contract matches the job. **Check ownership**: a copying array method creates a new outer array but keeps element references; a buffer transfer detaches the sender's buffer — different meanings of "copying". **Check when work happens**: iterator helpers pull lazily, array collection consumes everything, and a promise is a result handle rather than cancellation. **Check the language boundary**: syntax must parse in the target, methods must exist at runtime, and TypeScript declarations never install a missing API.

## 1. Match the Edition to the Behavior

Each edition adds behavior to a different part of the language. These are the changes most likely to affect application code and senior-level trade-offs.

**ES2022** added `Object.hasOwn`, `Error.cause`, public and private class fields, static initialization blocks, top-level await in modules, relative indexing through `at()`, and regular-expression match indices. Top-level await can delay evaluation of modules that depend on that module; private names are enforced by the language rather than by naming convention.

**ES2023** added copying array methods such as `toSorted()`, `toReversed()`, `toSpliced()`, and `with()`, plus `findLast()` and `findLastIndex()`. It also standardized hashbang comments and allowed most symbols as weak-collection keys. The copying methods create a new outer array but keep references to nested objects.

**ES2024** added `Object.groupBy()` and `Map.groupBy()`, `Promise.withResolvers()`, resizable and transferable ArrayBuffers, the regular-expression `v` flag, `Atomics.waitAsync()`, and string well-formedness methods. The `v` flag enables Unicode character-set intersection and subtraction, for example `/^[\p{Letter}&&\p{Script=Greek}]+$/v` matches Greek-script letters. Grouping shares its input items; transferring a buffer detaches the sender's view.

**ES2025** added synchronous iterator helpers and Set algebra; `RegExp.escape()`, scoped regular-expression modifiers, and duplicate named captures in mutually exclusive alternatives; `Promise.try()`; import attributes for JSON modules; and `Float16Array`. Iterator helpers are lazy and one-shot. `Promise.try()` invokes its callback immediately and turns a synchronous throw into a rejection. Binary16 data has less precision than a regular Number.

**ES2026** added `Array.fromAsync()`, `Iterator.concat()`, `getOrInsert()` and `getOrInsertComputed()` on Map and WeakMap, JSON reviver source access and `JSON.rawJSON()`, `Math.sumPrecise()`, `Error.isError()`, and Uint8Array base64/hex methods. `Array.fromAsync()` collects values into an array; `Iterator.concat()` composes a synchronous iterator lazily. `Math.sumPrecise()` still returns a Number, not an exact decimal.

Optional chaining and nullish coalescing arrived earlier, in ES2020, but remain common compatibility foundations. For example, `user?.address?.city` guards both links, while `user?.address.city` can still throw when address is null. The `??` operator defaults only for null or undefined, not for zero, an empty string, or false. The [ECMAScript 2026 specification](https://tc39.es/ecma262/2026/multipage/) describes the current edition; check the precise built-in contract before relying on an edge case.

## 2. Follow One Report Through the New APIs

Copying and grouping solve different parts of the report. Filtering and sorting create an ordered view; grouping then builds a new collection of arrays. None of these steps clones each row.

```javascript
const visible = rows
  .filter(row => row.active)
  .toSorted((a, b) => a.name.localeCompare(b.name));

const byTeam = Map.groupBy(visible, row => row.teamId);
const teamRows = byTeam.get(teamId) ?? [];

// visible !== rows; visible[0] may still be the same object as a row in rows.
```

Use `Object.groupBy` when group keys should become property keys, typically strings or symbols. It returns a null-prototype object, so use `Object.hasOwn` for membership checks. `Map.groupBy` retains key identity and is the clearer choice for object or numeric keys. `Object.groupBy` converts keys to strings or symbols, so numeric 1 and string "1" share a group. Both retain the original rows, so a consumer can still mutate shared objects.

## 3. Choose Lazy Iteration or Full Collection

ES2025 iterator helpers compose a synchronous source without building intermediate arrays. ES2026 `Array.fromAsync` consumes a sync or async iterable into an array and returns a promise. Use the first when the consumer should control how far it reads; use the second when the complete result is intentionally needed and fits memory.

```javascript
function* records() {
  for (let id = 1; id <= 1_000_000; id++) yield { id };
}

const firstHundred = Iterator.from(records())
  .filter(record => record.id % 2 === 0)
  .take(100);

for (const record of firstHundred) consume(record);

const allPages = await Array.fromAsync(pageSource(), normalizePage);
```

Iterator helpers are one-shot: consuming the iterator advances it. `Array.fromAsync` processes items in order and stores them all. For custom async iterators, a promise-valued iterator result is retained as an element when no mapper is supplied; an async generator has its own yield-adoption rules. A mapper's returned promise is awaited. `Iterator.concat` lazily sequences synchronous iterables in order; it leaves later sources untouched until iteration reaches them. Be explicit when those distinctions matter.

## 4. Let the Data Format Set the Precision Rule

ES2026 gives a JSON reviver access to the original source text for a primitive. That lets a schema recover a large integer before accepting the rounded Number. `JSON.rawJSON` can then emit validated primitive JSON text without first converting it through Number.

```javascript
const record = JSON.parse('{"id":9007199254740993}', (key, value, context) =>
  key === 'id' && /^\d+$/.test(context.source) ? BigInt(context.source) : value
);

const wire = JSON.stringify({ id: JSON.rawJSON(record.id.toString()) });
// {"id":9007199254740993}
```

This is a field-specific wire-format decision, not general arbitrary-precision JSON. Validate that the field is an integer token before converting it, and ensure consumers preserve the token too. `JSON.rawJSON` accepts only primitive JSON text.

A few newer built-ins address narrower problems. `getOrInsert()` distinguishes an absent key from a present key whose value is `undefined`; `getOrInsertComputed()` calls its factory only for a missing key. Because JavaScript evaluates arguments before a method call, `map.getOrInsert(key, buildDefault())` still runs `buildDefault()` on a hit. `RegExp.escape()` quotes literal input for a pattern, `Promise.try()` turns an immediate return or throw into a promise result, and Set methods express set algebra. `Math.sumPrecise()` reduces rounding error but still returns a Number; `Error.isError()` recognizes Error objects across realms; and `Uint8Array` base64 and hex methods decode or encode bytes. When decoding external input, choose the alphabet and validation policy explicitly.

## 5. Keep Host APIs and Runtime Support Separate

`structuredClone` is a host API, not an ECMAScript edition feature. It clones supported object graphs, including cycles, under its own type rules; see the [copying chapter](../04-memory-and-data/10.1.4.03-shallow-vs-deep-copy.md) for its ownership boundary. It is not uniformly faster than JSON serialization: choose by the data contract, then benchmark representative data if performance matters. A type checker may accept a method that the deployed runtime does not implement, so check build syntax support and runtime methods separately.

## Summary

Recent editions add safer array updates, grouping, iterator composition, async collection, data-format tools, and focused built-ins. Select the API by mutation, identity, evaluation timing, and precision. Then verify its syntax or method in the actual deployment target; a release year is not a support guarantee.

# GSAP (GreenSock Animation Platform)

A product hero needs its title, description, and call to action to enter in a deliberate overlap. The sequence may also need to pause, reverse, or follow scroll position. GSAP gives these effects one controllable playhead.

```javascript
import { gsap } from 'gsap';

const intro = gsap.timeline({ defaults: { ease: 'power2.out' } });

intro
  .fromTo('.title', { y: 24, autoAlpha: 0 }, { y: 0, autoAlpha: 1, duration: 0.5 })
  .fromTo('.description', { y: 16, autoAlpha: 0 }, { y: 0, autoAlpha: 1, duration: 0.4 }, '-=0.2');
// UI handlers can later call intro.pause(), intro.reverse(), or intro.seek(seconds).
```

## Definition

GSAP is a JavaScript animation library. A tween changes target properties over time; a timeline places and controls several tweens on one playhead. Plugins such as ScrollTrigger connect playback to scroll position or element entry.

> **Textbook Definition:** GSAP schedules imperative property interpolation through tweens and coordinated timelines. A timeline's positions, easing, and playback controls determine how effects progress; the application must scope targets and release animation work with the owning interface.

## First Principles

A GSAP animation answers three questions. **A tween answers what changes**: it interpolates target properties from a start or current value to an end value over a duration. **A timeline answers when each change happens**: its playhead coordinates child tweens, overlaps, labels, seeking, reversal, and scroll-linked progress. **The interface owns the animation**: a component or page creates the timeline, scopes its targets, and removes it when the owner goes away. Property choice still controls rendering work — GSAP schedules updates but cannot make layout, paint, or expensive callbacks free.

## 1. Follow One Sequence

A title should appear first, the description should overlap its last 0.2 seconds, and the call to action should follow. The timeline makes these positions explicit:

```javascript
import { gsap } from 'gsap';

const intro = gsap.timeline({
  defaults: { ease: 'power2.out' },
});

intro
  .addLabel('start')
  .fromTo(
    '.title',
    { y: 24, autoAlpha: 0 },
    { y: 0, autoAlpha: 1, duration: 0.5, immediateRender: false },
    'start',
  )
  .fromTo(
    '.description',
    { y: 16, autoAlpha: 0 },
    { y: 0, autoAlpha: 1, duration: 0.4, immediateRender: false },
    '-=0.2',
  )
  .fromTo(
    '.cta',
    { scale: 0.96, autoAlpha: 0 },
    { scale: 1, autoAlpha: 1, duration: 0.3, immediateRender: false },
    '+=0.1',
  );

// UI handlers can later call intro.pause(), intro.reverse(), or intro.seek(seconds).
```

The title occupies 0–0.5 seconds. The description starts at 0.3 and ends at 0.7; the call to action starts at 0.8. The position string "-=0.2" overlaps the current timeline end, while "+=0.1" adds a gap after it. Easing changes progress within an interval; it does not change when that interval starts.

For one property change, a standalone gsap.to() is enough. Use from() when the current target value is the destination, and fromTo() when both endpoints must be explicit. A timeline is valuable when steps need shared control, not merely because more than one property changes.

## 2. Connect Playback to Scrolling

A timeline is time-driven until another controller changes its playhead. ScrollTrigger can map scroll progress to that playhead or fire an effect when a trigger crosses a start position:

```javascript
import { gsap } from 'gsap';
import { ScrollTrigger } from 'gsap/ScrollTrigger';

gsap.registerPlugin(ScrollTrigger);

const story = gsap.timeline({
  scrollTrigger: {
    trigger: '.story',
    start: 'top top',
    end: '+=500',
    pin: true,
    scrub: true,
  },
});

story.fromTo('.story-image', { yPercent: 12 }, { yPercent: -12, ease: 'none' });
```

With scrub, scroll position controls progress directly; a numeric scrub value smooths that response. Without scrub, ScrollTrigger can start an ordinary time-based tween at a configured threshold. These are different interactions: use an observer for a simple enter/leave cue when a controllable timeline adds no value. Pinning changes page flow and should be tested with the surrounding layout and keyboard navigation.

## 3. Give React an Owner

In React, create animations inside useGSAP from @gsap/react. The hook scopes selector text to a ref and uses a GSAP context to revert animations and ScrollTriggers on cleanup. In a React Server Component app, put this interactive code behind a client boundary.

```tsx
'use client';

import { useRef } from 'react';
import { gsap } from 'gsap';
import { ScrollTrigger } from 'gsap/ScrollTrigger';
import { useGSAP } from '@gsap/react';

gsap.registerPlugin(useGSAP, ScrollTrigger);

export function Story() {
  const scope = useRef<HTMLElement>(null);

  useGSAP(() => {
    const media = gsap.matchMedia(scope);

    media.add('(prefers-reduced-motion: no-preference)', () => {
      const timeline = gsap.timeline({
        scrollTrigger: {
          trigger: '.story',
          start: 'top 80%',
          end: 'bottom 20%',
          scrub: true,
        },
      });

      timeline.fromTo('.story-image', { y: 24 }, { y: 0, ease: 'none' });
    });

    return () => media.revert();
  }, { scope });

  return (
    <section className="story" ref={scope}>
      <h2>Visible before animation</h2>
      <img className="story-image" src="/story.jpg" alt="" />
    </section>
  );
}
```

The base content remains visible if JavaScript or the optional motion is unavailable. The media query reverts the animation when the user enables reduced motion or the component unmounts. If a click handler creates an animation later, wrap that callback with the hook's contextSafe helper so the hook can record its work; remove manually installed event listeners separately. When dependencies should rebuild the effect, provide them explicitly and set revertOnUpdate.

## 4. Choose the Control the Interaction Needs

| Need | Suitable starting point |
| ---------------------------------------------- | ------------------------------------------------------------------------ |
| A small state change between two styles | CSS transition |
| React entry/exit or layout identity | Motion for React |
| A reversible, labeled sequence | GSAP timeline |
| Browser-owned playback object and cancellation | Web Animations API |
| Progress tied to scroll position | CSS scroll timeline or ScrollTrigger, based on support and control needs |

GSAP's ticker, scroll measurements, and callbacks still use JavaScript. A transform can reduce repeated layout work, but large layers, paint-heavy effects, long tasks, and pinning can still miss frames. Record the complete interaction in the target browser and inspect layout, paint, scripting, and compositing rather than relying on a library name or a fixed bundle-size estimate.

## Summary

Use a tween for one change and a timeline when sequence, overlap, reversal, or seeking matters. Bind the timeline to scroll only when progress must follow scroll position. In React, scope work to its owner, revert it on cleanup, respect reduced motion, and measure the finished interaction.

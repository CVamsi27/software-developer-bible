# React Spring

> React Spring is a spring-physics-based animation library for React. Unlike CSS transitions or GSAP timelines, it uses natural spring physics (mass, tension, friction) to create fluid, natural-feeling motion that adapts to user input and interrupts.

## Definition

React Spring animates values for React through spring dynamics, with additional duration/easing and decay configurations. Target-specific packages provide animated elements on the web, React Native and other renderers. Hooks manage values/controllers; `animated` elements apply those values without requiring a React render for every animation frame.

## First Principles

A toggle can change its target again before motion finishes. Starting a fixed animation from its original starting point creates a jump. A spring controller tracks the current value and velocity, then responds to the new target. Mass, tension and friction determine that response. A settling time is an outcome of the model and stopping threshold, not an exact schedule guarantee.

## Follow a target change

```tsx
import { useState } from 'react';
import { animated, useReducedMotion, useSpring } from '@react-spring/web';

export function MovingMarker() {
  const [right, setRight] = useState(false);
  const reducedMotion = useReducedMotion();
  const styles = useSpring({
    x: right ? 160 : 0,
    immediate: Boolean(reducedMotion),
    config: { mass: 1, tension: 220, friction: 26 },
  });
  return (
    <div>
      <button type="button" onClick={() => setRight(value => !value)}>Move marker</button>
      <animated.div aria-hidden="true" style={{
        width: 20, height: 20, background: 'currentColor',
        transform: styles.x.to(value => `translateX(${value}px)`),
      }} />
    </div>
  );
}
```

Click once: React changes the target to 160 → the spring updates `x` over frames → interpolation turns each number into a transform → `animated.div` applies the value. Click again during movement: the target becomes 0 and the existing spring responds from its current state. Reduced motion makes the position change immediate; the control remains available.

```text
React state → target → spring value/controller → interpolation → animated element
```

The spring value is not ordinary React state. Avoid copying every frame into state just to render it. Other React state or prop changes can still rerender the component, so "no React renders" applies to the animated value updates, not the component's entire lifetime.

## Choose the hook by what it owns

| Hook | Role in the animation |
| ---------------- | ------------------------------------------------------- |
| `useSpring` | One controller with one or several animated properties |
| `useSprings` | Several independently configured controllers |
| `useTrail` | Related controllers following one another |
| `useTransition` | Item entry/update/exit lifecycle, with stable item keys |
| `useChain` | Scheduling controllers referenced through spring refs |
| `useSpringValue` | A single animated value without a multi-property object |

A trail is spring-following behavior, not necessarily a fixed stagger delay. With `useChain(refs, timeSteps, timeFrame)`, time steps are fractions of the configured time frame, not percentages of another spring's completion. Without supplied time steps, sequencing uses completion. Use an explicit timeline when an exact editorial schedule matters.

## Configuration and gestures are separate mechanisms

Increasing tension strengthens the pull; friction damps velocity; mass changes response for the same force. Other options include velocity, clamping, precision and duration/easing. Start from a documented preset, then evaluate the actual motion. A physics calculation can be deterministic for given inputs; its wall-clock appearance still depends on frame scheduling and interaction.

A gesture library such as `@use-gesture/react` can supply positions/velocities to the spring. There is no general `@react-spring/gesture` package in this API. Gesture state, bounds, cancellation and keyboard alternatives remain application responsibilities.

## Compare control needs

Motion's React API provides declarative animation, gestures and layout-animation facilities; React Spring emphasizes animated values and controller composition. GSAP provides timeline-oriented control. These capabilities overlap, so pick by the required lifecycle and integrations rather than invented fixed bundle sizes. Measure the actual version and imports in the production build.

Transforms and opacity often avoid layout and can be composited efficiently, but an animated element does not guarantee GPU-only work. Profile the full frame, retained values and expensive SVG/CSS effects. Define cleanup for external subscriptions and respect reduced-motion preferences.

## Summary

Trace target → controller → animated value → element. Use springs for motion that responds to changing targets, choose hooks by ownership and use explicit scheduling when time alignment matters. Keep gestures, accessibility and rendering cost visible as separate boundaries.

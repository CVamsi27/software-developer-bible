# Webhooks — Delivery, Verification, Retry, Security


## Webhook Architecture

**What are webhooks?** Webhooks are HTTP callbacks — when something happens in your system (e.g., appointment booked), you send an HTTP POST to a URL the consumer registered. They're the opposite of polling: instead of the consumer repeatedly asking "anything new?", your system pushes notifications to them. Webhooks are essential for integrations — payment providers, email services, and third-party apps all use webhooks to notify your system of events.

```typescript
interface Webhook {

// Register webhook
@Post('webhooks')
async create(@Body() data: CreateWebhookDto): Promise<Webhook> {
  // Validate URL
  const url = new URL(data.url);
  if (!['http:', 'https:'].includes(url.protocol)) {
    throw new BadRequestException('URL must use HTTP or HTTPS');
  }

  // Generate secret for signature verification
  const secret = crypto.randomBytes(32).toString('hex');

  return prisma.webhook.create({
    data: {
      url: data.url,
      events: data.events,
      secret,
      clinicId: req.user.clinicId,
      active: true
    }
  });
}
```

## Webhook Delivery

```typescript
// Webhook worker implementation
class WebhookWorker {
  async processEvent(event: WebhookEvent): Promise<void> {
    // Find all webhooks subscribed to this event type
    const webhooks = await prisma.webhook.findMany({
      where: {
        clinicId: event.clinicId,
        events: { has: event.type },
        active: true
      }
    });

    // Deliver to each webhook
    await Promise.allSettled(
      webhooks.map(webhook => this.deliver(webhook, event))
    );
  }

  async deliver(webhook: Webhook, event: WebhookEvent): Promise<void> {
    const payload = {
      id: event.id,
      type: event.type,
      data: event.data,
      createdAt: event.createdAt
    };

    // Generate signature
    const signature = this.generateSignature(payload, webhook.secret);

    // Send request
    const response = await fetch(webhook.url, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'X-Webhook-Signature': signature,
        'X-Webhook-ID': webhook.id,
        'X-Webhook-Timestamp': Date.now().toString(),
        'User-Agent': 'Docita-Webhook/1.0'
      },
      body: JSON.stringify(payload),
      signal: AbortSignal.timeout(10000) // 10s timeout
    });

    if (!response.ok) {
      throw new WebhookDeliveryError(`HTTP ${response.status}`);
    }

    // Update delivery stats
    await prisma.webhook.update({
      where: { id: webhook.id },
      data: {
        lastTriggeredAt: new Date(),
        failureCount: 0
      }
    });
  }
}
```

## Signature Verification (Consumer Side)

**Why verify signatures?** Anyone can send an HTTP POST to your webhook endpoint. Without verification, an attacker could fake webhook events (e.g., fake a payment confirmation). HMAC signatures prove the request came from the real sender: the sender signs the payload with a shared secret, and you verify the signature before processing. The `timingSafeEqual` function is critical — regular string comparison leaks timing information that attackers can exploit.


```typescript
// Generate signature (producer)
function generateSignature(payload: any, secret: string): string {
  const body = JSON.stringify(payload);
  return crypto
    .createHmac('sha256', secret)
    .update(body)
    .digest('hex');
}

// Verify signature (consumer)
function verifySignature(
  payload: string,
  signature: string,
  secret: string
): boolean {
  const expectedSignature = crypto
    .createHmac('sha256', secret)
    .update(payload)
    .digest('hex');

  // Constant-time comparison to prevent timing attacks
  return crypto.timingSafeEqual(
    Buffer.from(signature),
    Buffer.from(expectedSignature)
  );
}

// NestJS webhook handler
@Post('webhooks/docita')
async handleWebhook(
  @Headers('x-webhook-signature') signature: string,
  @Headers('x-webhook-timestamp') timestamp: string,
  @Body() payload: any
): Promise<void> {
  // Verify timestamp (prevent replay attacks)
  const requestTime = parseInt(timestamp);
  const now = Date.now();
  if (Math.abs(now - requestTime) > 300000) { // 5 minutes
    throw new UnauthorizedException('Timestamp too old');
  }

  // Verify signature
  const body = JSON.stringify(payload);
  if (!verifySignature(body, signature, process.env.WEBHOOK_SECRET)) {
    throw new UnauthorizedException('Invalid signature');
  }

  // Process event
  await this.processEvent(payload);
}
```

## Retry Strategy

```typescript
// Exponential backoff with jitter
class WebhookRetryStrategy {
  private maxRetries = 5;
  private baseDelay = 1000; // 1 second

  async executeWithRetry(
    fn: () => Promise<void>,
    attempt: number = 0
  ): Promise<void> {
    try {
      await fn();
    } catch (error) {
      if (attempt >= this.maxRetries) {
        throw new WebhookDeliveryError('Max retries exceeded');
      }

      // Exponential backoff with jitter
      const delay = this.baseDelay * Math.pow(2, attempt);
      const jitter = Math.random() * 1000;
      await sleep(delay + jitter);

      await this.executeWithRetry(fn, attempt + 1);
    }
  }
}

// Retry schedule
const retrySchedule = {
  1: '1s',
  2: '2s',
  3: '4s',
  4: '8s',
  5: '16s',
  // Total: ~31 seconds before giving up
};
```

## Dead Letter Queue

```typescript
// Move failed webhooks to DLQ
async function moveToDLQ(event: WebhookEvent, error: string): Promise<void> {
  await prisma.webhookDeadLetter.create({
    data: {
      eventId: event.id,
      eventType: event.type,
      payload: event.data,
      error,
      attempts: 5,
      createdAt: new Date()
    }
  });

  // Alert admin
  await alertService.alert({
    severity: 'MEDIUM',
    message: `Webhook delivery failed after 5 attempts`,
    details: {
      eventType: event.type,
      clinicId: event.clinicId,
      error
    }
  });
}

// Replay from DLQ
async function replayFromDLQ(dlqId: string): Promise<void> {
  const dlqEntry = await prisma.webhookDeadLetter.findUnique({
    where: { id: dlqId }
  });

  if (!dlqEntry) {
    throw new NotFoundException('DLQ entry not found');
  }

  // Re-process the event
  await webhookWorker.processEvent({
    id: dlqEntry.eventId,
    type: dlqEntry.eventType,
    data: dlqEntry.payload,
    clinicId: dlqEntry.clinicId,
    createdAt: dlqEntry.createdAt
  });

  // Remove from DLQ
  await prisma.webhookDeadLetter.delete({
    where: { id: dlqId }
  });
}
```

## Webhook Security Best Practices

```typescript
const webhookSecurity = {
  // 1. Always use HTTPS
  requireHTTPS: true,

  // 2. Sign payloads with HMAC
  signing: {
    algorithm: 'sha256',

};
```

## Idempotency

```typescript
// Idempotency check for webhooks
async function handleWebhookWithIdempotency(
  webhookId: string,
  eventId: string,
  handler: () => Promise<void>
): Promise<void> {
  // Check if already processed
  const existing = await prisma.webhookDelivery.findUnique({
    where: {
      webhookId_eventId: { webhookId, eventId }
    }
  });

  if (existing) {
    console.log(`Webhook ${eventId} already processed`);
    return;
  }

  // Process and record
  try {
    await handler();
    
    await prisma.webhookDelivery.create({
      data: {
        webhookId,
        eventId,
        status: 'delivered',
        processedAt: new Date()
      }
    });
  } catch (error) {
    await prisma.webhookDelivery.create({
      data: {
        webhookId,
        eventId,
        status: 'failed',
        error: error.message,
        processedAt: new Date()
      }
    });
    throw error;
  }
}
```

## Interview Tips
- Explain webhook delivery flow (event → queue → HTTP POST → retry)
- Know HMAC signature verification (constant-time comparison)
- Discuss timestamp validation (prevent replay attacks)
- Explain idempotency for webhooks (deduplicate by event ID)
- Know retry strategy (exponential backoff with jitter)
- Discuss DLQ for failed webhooks

# Event-Driven Architecture — Kafka, Event Sourcing, CQRS

## Event-Driven Patterns

| Pattern | Description | Use Case |
|---------|-------------|----------|
| **Event Notification** | Publish events, consumers react | User created → send welcome email |
| **Event-Carried State Transfer** | Events contain full state | Order event with all order data |
| **Event Sourcing** | Store events, derive state | Audit trail, temporal queries |
| **CQRS** | Separate read/write models | High-read, low-write scenarios |

## Kafka Architecture

**What is Kafka?** Apache Kafka is a distributed event streaming platform. Think of it as a persistent, fault-tolerant, high-throughput message queue. Events (called "records") are written to topics (like database tables), which are split into partitions (for parallelism). Producers write events, consumers read them. Unlike traditional message queues, Kafka retains events for a configurable time (e.g., 7 days) — consumers can replay events from any point in time. This makes Kafka ideal for event sourcing, log aggregation, and real-time data pipelines.

### Consumer Implementation
```typescript

const consumer: Consumer = kafka.consumer({
  groupId: 'appointment-processor',
  sessionTimeout: 30000,
  heartbeatInterval: 3000
});

await consumer.subscribe({ topic: 'appointments', fromBeginning: false });

await consumer.run({
  eachMessage: async ({ topic, partition, message }: EachMessagePayload) => {
    const event = JSON.parse(message.value!.toString());
    
    // Idempotency check
    const processed = await checkIfProcessed(event.metadata.correlationId);
    if (processed) {
      console.log(`Event ${event.metadata.correlationId} already processed`);
      return;
    }
    
    // Process event
    switch (event.eventType) {
      case 'APPOINTMENT_CREATED':
        await handleAppointmentCreated(event.payload);
        break;
      case 'APPOINTMENT_CANCELLED':
        await handleAppointmentCancelled(event.payload);
        break;
    }
    
    // Mark as processed
    await markAsProcessed(event.metadata.correlationId);
  }
});
```

## Event Sourcing

**What is event sourcing?** Instead of storing the current state of an entity (e.g., `appointment.status = "cancelled"`), you store every change as an immutable event (e.g., `APPOINTMENT_CREATED`, `APPOINTMENT_CONFIRMED`, `APPOINTMENT_CANCELLED`). The current state is derived by replaying all events. Benefits: complete audit trail (who changed what and when), ability to reconstruct state at any point in time, and natural fit for distributed systems (events can be replayed to rebuild failed services). Cost: more storage, more complex reads (you need projections for fast queries).


### Event Store Schema
```sql
-- Events table
CREATE TABLE events (
  id UUID DEFAULT gen_random_uuid(),
  aggregate_id UUID NOT NULL,
  aggregate_type VARCHAR(50) NOT NULL,
  event_type VARCHAR(100) NOT NULL,
  payload JSONB NOT NULL,
  metadata JSONB NOT NULL,
  version INTEGER NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  
  UNIQUE(aggregate_id, version)
);

-- Snapshots table
CREATE TABLE snapshots (
  aggregate_id UUID PRIMARY KEY,
  aggregate_type VARCHAR(50) NOT NULL,
  state JSONB NOT NULL,
  version INTEGER NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Indexes
CREATE INDEX idx_events_aggregate ON events (aggregate_id, version);
CREATE INDEX idx_events_type ON events (event_type, created_at);
CREATE INDEX idx_events_created ON events (created_at);
```

### Event Sourcing Implementation
```typescript
// Appointment Aggregate
class AppointmentAggregate {
  private id: string;
  private clinicId: string;
  private patientId: string;
  private scheduledAt: Date;
  private status: 'scheduled' | 'confirmed' | 'cancelled' | 'completed';
  private version: number = 0;
  private changes: Event[] = [];

  // Command: Schedule Appointment
  schedule(data: ScheduleAppointmentCommand): void {
    // Business rules
    if (this.status && this.status !== 'cancelled') {
      throw new Error('Appointment already exists');
    }
    
    // Emit event
    this.apply({
      eventType: 'APPOINTMENT_SCHEDULED',
      payload: {
        clinicId: data.clinicId,
        patientId: data.patientId,
        scheduledAt: data.scheduledAt
      }
    });
  }

  // Command: Confirm Appointment
  confirm(): void {
    if (this.status !== 'scheduled') {
      throw new Error('Can only confirm scheduled appointments');
    }
    
    this.apply({
      eventType: 'APPOINTMENT_CONFIRMED',
      payload: {}
    });
  }

  // Command: Cancel Appointment
  cancel(reason: string): void {
    if (this.status === 'completed') {
      throw new Error('Cannot cancel completed appointments');
    }
    
    this.apply({
      eventType: 'APPOINTMENT_CANCELLED',
      payload: { reason }
    });
  }

  // Apply event to state
  private apply(event: Omit<Event, 'id' | 'aggregateId' | 'version' | 'createdAt'>): void {
    this.version++;
    const fullEvent: Event = {
      id: uuid(),
      aggregateId: this.id,
      version: this.version,
      createdAt: new Date(),
      ...event
    };
    
    this.changes.push(fullEvent);
    this.applyEvent(fullEvent);
  }

  private applyEvent(event: Event): void {
    switch (event.eventType) {
      case 'APPOINTMENT_SCHEDULED':
        this.clinicId = event.payload.clinicId;
        this.patientId = event.payload.patientId;
        this.scheduledAt = new Date(event.payload.scheduledAt);
        this.status = 'scheduled';
        break;
      case 'APPOINTMENT_CONFIRMED':
        this.status = 'confirmed';
        break;
      case 'APPOINTMENT_CANCELLED':
        this.status = 'cancelled';
        break;
    }
  }

  // Get uncommitted events
  getUncommittedChanges(): Event[] {
    return this.changes;
  }

  // Load from history
  loadFromHistory(events: Event[]): void {
    events.forEach(event => this.applyEvent(event));
    this.version = events.length;
  }
}
```

### Repository Pattern
```typescript
class AppointmentRepository {
  constructor(private eventStore: EventStore) {}

  async save(aggregate: AppointmentAggregate): Promise<void> {
    const events = aggregate.getUncommittedChanges();
    
    // Optimistic concurrency check
    const currentVersion = await this.getCurrentVersion(aggregate.id);
    if (currentVersion !== aggregate.version - events.length) {
      throw new ConcurrencyError('Aggregate has been modified');
    }
    
    // Store events
    await this.eventStore.appendEvents(aggregate.id, events);
    
    // Create snapshot if needed
    if (aggregate.version % 100 === 0) {
      await this.createSnapshot(aggregate);
    }
  }

  async getById(id: string): Promise<AppointmentAggregate> {
    // Try to load from snapshot
    const snapshot = await this.eventStore.getSnapshot(id);
    
    const events = await this.eventStore.getEvents(id, snapshot?.version || 0);
    
    const aggregate = new AppointmentAggregate(id);
    if (snapshot) {
      aggregate.loadFromSnapshot(snapshot.state);
    }
    aggregate.loadFromHistory(events);
    
    return aggregate;
  }
}
```

## CQRS (Command Query Responsibility Segregation)

### Read Model (Projections)
```typescript
// Projection: Build read model from events
class AppointmentProjection {
  constructor(private readDb: Database) {}

  async project(event: Event): Promise<void> {
    switch (event.eventType) {
      case 'APPOINTMENT_SCHEDULED':
        await this.readDb.appointments.create({
          id: event.aggregateId,
          clinicId: event.payload.clinicId,
          patientId: event.payload.patientId,
          scheduledAt: event.payload.scheduledAt,
          status: 'scheduled',
          createdAt: event.createdAt
        });
        break;
        
      case 'APPOINTMENT_CONFIRMED':
        await this.readDb.appointments.update(
          { id: event.aggregateId },
          { status: 'confirmed', confirmedAt: event.createdAt }
        );
        break;
        
      case 'APPOINTMENT_CANCELLED':
        await this.readDb.appointments.update(
          { id: event.aggregateId },
          { status: 'cancelled', cancelledAt: event.createdAt }
        );
        break;
    }
  }
}
```

### Query Handler
```typescript
class AppointmentQueryHandler {
  constructor(private readDb: Database) {}

  async handle(query: GetAppointmentsQuery): Promise<Appointment[]> {
    return this.readDb.appointments.findMany({
      where: {
        clinicId: query.clinicId,
        scheduledAt: {
          gte: query.startDate,
          lte: query.endDate
        }
      },
      orderBy: { scheduledAt: 'asc' }
    });
  }
}
```

## Failure Modes and Recovery

### Event Processing Failures
```typescript
// Dead Letter Queue (DLQ) pattern
class EventProcessor {
  async process(event: Event): Promise<void> {
    try {
      await this.handleEvent(event);
    } catch (error) {
      if (event.retryCount < 3) {
        // Retry with exponential backoff
        await this.retryQueue.add(event, {
          delay: Math.pow(2, event.retryCount) * 1000
        });
      } else {
        // Move to DLQ
        await this.dlq.add({
          event,
          error: error.message,
          failedAt: new Date()
        });
        
        // Alert
        await this.alertService.alert({
          severity: 'HIGH',
          message: `Event ${event.id} failed after 3 retries`,
          details: { eventType: event.eventType, error: error.message }
        });
      }
    }
  }
}
```

### Reprocessing Events
```typescript
// Reprocess events from specific point in time
class EventReprocessor {
  async reprocess(fromDate: Date, toDate: Date, eventTypes: string[]): Promise<void> {
    const events = await this.eventStore.getEventsByDateRange(fromDate, toDate);
    
    for (const event of events) {
      if (eventTypes.includes(event.eventType)) {
        await this.processEvent(event);
      }
    }
  }
}
```

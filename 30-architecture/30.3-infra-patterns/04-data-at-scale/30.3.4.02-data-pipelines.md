# Data Pipelines — ETL, Stream Processing, Data Lake

## Pipeline Patterns

| Pattern                 | Description                      | Use Case                     |
| ----------------------- | -------------------------------- | ---------------------------- |
| **Batch ETL**           | Process data in batches          | Daily reports, analytics     |
| **Stream Processing**   | Process data in real-time        | Real-time dashboards, alerts |
| **Lambda Architecture** | Batch + stream together          | Historical + real-time views |
| **Kappa Architecture**  | Stream only, reprocess if needed | Simpler architecture         |

---


## Batch Processing (ETL)

**What is ETL?** Extract-Transform-Load: you Extract data from a source (database, API, file), Transform it (clean, aggregate, enrich), and Load it into a destination (analytics database, data warehouse). ETL runs in batches — e.g., every night at 2 AM, process all of yesterday's appointments into analytics records. This is the backbone of business intelligence, reporting, and data analytics. For Docita, ETL would aggregate appointment data into clinic performance metrics.


### Node.js Batch Job
```typescript
class BatchProcessor {
  private batchSize: number = 1000;

  async processAppointments(date: Date): Promise<BatchResult> {
    const result: BatchResult = {
      processed: 0,
      errors: 0,
      startTime: new Date()
    };

    // Extract
    const appointments = await this.extract(date);
    
    // Transform (in batches)
    for (let i = 0; i < appointments.length; i += this.batchSize) {
      const batch = appointments.slice(i, i + this.batchSize);
      
      try {
        const transformed = await this.transform(batch);
        await this.load(transformed);
        result.processed += batch.length;
      } catch (error) {
        result.errors += batch.length;
        console.error(`Batch ${i} failed:`, error);
      }
    }

    result.endTime = new Date();
    return result;
  }

  private async extract(date: Date): Promise<Appointment[]> {
    return prisma.appointment.findMany({
      where: {
        scheduledAt: {
          gte: startOfDay(date),
          lte: endOfDay(date)
        }
      }
    });
  }

  private async transform(appointments: Appointment[]): Promise<AnalyticsRecord[]> {
    return appointments.map(apt => ({
      appointmentId: apt.id,
      clinicId: apt.clinicId,
      patientId: apt.patientId,
      scheduledDate: apt.scheduledAt,
      status: apt.status,
      duration: this.calculateDuration(apt),
      isNoShow: apt.status === 'no-show'
    }));
  }

  private async load(records: AnalyticsRecord[]): Promise<void> {
    await prisma.analytics.createMany({ data: records });
  }
}
```

### Scheduled Execution
```typescript
// Using node-cron for batch jobs
import cron from 'node-cron';

// Daily at 2 AM
cron.schedule('0 2 * * *', async () => {
  const processor = new BatchProcessor();
  const result = await processor.processAppointments(new Date());
  
  console.log(`Batch complete: ${result.processed} processed, ${result.errors} errors`);
  
  // Alert if errors
  if (result.errors > 0) {
    await alertService.alert({
      severity: 'MEDIUM',
      message: `Batch job completed with ${result.errors} errors`
    });
  }
});
```

## Stream Processing (Kafka)

**Batch vs Stream:** Batch processes data periodically (every hour/day), stream processes data in real-time as events arrive. If you need to know about an appointment cancellation within seconds (to update a dashboard), you use stream processing. If you need a daily report of all appointments, you use batch processing. Most production systems use both — batch for historical analytics, stream for real-time dashboards and alerts.


### Real-time Event Processing
```typescript
class StreamProcessor {
  private consumer: Consumer;
  private producer: Producer;

  async start(): Promise<void> {
    await this.consumer.subscribe({ topic: 'appointments' });
    
    await this.consumer.run({
      eachMessage: async ({ message }) => {
        const event = JSON.parse(message.value!.toString());
        
        // Process in real-time
        await this.processEvent(event);
        
        // Produce to downstream topic
        await this.producer.send({
          topic: 'appointment-analytics',
          messages: [{
            key: event.clinicId,
            value: JSON.stringify({
              ...event,
              processedAt: new Date()
            })
          }]
        });
      }
    });
  }

  private async processEvent(event: AppointmentEvent): Promise<void> {
    // Update real-time metrics
    await this.updateMetrics(event);
    
    // Check for anomalies
    if (this.isAnomaly(event)) {
      await this.alertAnomaly(event);
    }
    
    // Update cache
    await this.updateCache(event);
  }
}
```

### Windowed Aggregations
```typescript
// Sliding window aggregation
class WindowedAggregator {
  private windows: Map<string, Event[]> = new Map();

  async processEvent(event: Event): Promise<void> {
    const windowKey = this.getWindowKey(event);
    
    if (!this.windows.has(windowKey)) {
      this.windows.set(windowKey, []);
    }
    
    this.windows.get(windowKey)!.push(event);
    
    // Check if window is complete
    if (this.isWindowComplete(windowKey)) {
      const aggregation = this.aggregate(this.windows.get(windowKey)!);
      await this.storeAggregation(aggregation);
      this.windows.delete(windowKey);
    }
  }

  private getWindowKey(event: Event): string {
    // 5-minute windows
    const windowStart = Math.floor(event.timestamp.getTime() / (5 * 60 * 1000)) * (5 * 60 * 1000);
    return `${event.type}:${windowStart}`;
  }
}
```

## Data Quality

### Validation Pipeline
```typescript
class DataValidator {
  async validate(data: any[], schema: Schema): Promise<ValidationResult> {
    const errors: ValidationError[] = [];
    const valid: any[] = [];

    for (const record of data) {
      const result = schema.validate(record);
      if (result.error) {
        errors.push({
          record,
          error: result.error.message,
          field: result.error.details[0].path
        });
      } else {
        valid.push(result.value);
      }
    }

    return {
      valid: valid.length,
      invalid: errors.length,
      errors,
      validRecords: valid
    };
  }
}
```

## Backfill and Reprocessing

### Backfill Strategy
```typescript
class BackfillProcessor {
  async backfill(startDate: Date, endDate: Date): Promise<void> {
    const days = eachDayOfInterval({ start: startDate, end: endDate });
    
    for (const day of days) {
      console.log(`Processing ${day.toISOString()}`);
      
      // Extract from source
      const data = await this.extract(day);
      
      // Transform
      const transformed = await this.transform(data);
      
      // Load to target
      await this.load(transformed, day);
      
      // Verify
      await this.verify(day);
    }
  }
}
```

### Idempotent Processing
```typescript
// Ensure idempotent processing
async function processRecord(record: Record): Promise<void> {
  // Check if already processed
  const existing = await prisma.processedRecord.findUnique({
    where: { recordId: record.id }
  });
  
  if (existing) {
    console.log(`Record ${record.id} already processed`);
    return;
  }
  
  // Process
  await transformAndLoad(record);
  
  // Mark as processed
  await prisma.processedRecord.create({
    data: {
      recordId: record.id,
      processedAt: new Date()
    }
  });
}
```

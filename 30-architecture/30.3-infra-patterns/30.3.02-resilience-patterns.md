# Resilience Patterns — Circuit Breaker, Bulkhead, Retry, Idempotency


## Circuit Breaker

**What problem does it solve?** When a downstream service (e.g., SendGrid for emails) is slow or down, your app keeps sending requests to it. Each request waits 30 seconds to time out, tying up threads and connections. Eventually your whole app is stuck waiting. The circuit breaker prevents this: after N failures, it "trips" and immediately rejects requests without calling the downstream service. After a cooldown period, it lets one request through to test if the service recovered. If it succeeds, the circuit closes; if it fails, it opens again.


### States
```typescript
enum CircuitState {
  CLOSED = 'CLOSED', // Normal operation
  OPEN = 'OPEN', // Failing, reject requests
  HALF_OPEN = 'HALF_OPEN' // Testing if service recovered
}

interface CircuitBreakerConfig {
  failureThreshold: number; // Failures before opening
  successThreshold: number; // Successes before closing
  timeout: number; // Time in OPEN state (ms)
  monitoringPeriod: number; // Window for counting failures (ms)
}
```

### Implementation
```typescript
class CircuitBreaker {
  private state: CircuitState = CircuitState.CLOSED;
  private failureCount: number = 0;
  private successCount: number = 0;
  private lastFailureTime: number = 0;
  private nextAttempt: number = 0;

  constructor(private config: CircuitBreakerConfig) {}

  async execute<T>(fn: () => Promise<T>): Promise<T> {
    if (this.state === CircuitState.OPEN) {
      if (Date.now() > this.nextAttempt) {
        this.state = CircuitState.HALF_OPEN;
        this.successCount = 0;
      } else {
        throw new CircuitOpenError('Circuit is open');
      }
    }

    try {
      const result = await fn();
      this.onSuccess();
      return result;
    } catch (error) {
      this.onFailure();
      throw error;
    }
  }

  private onSuccess(): void {
    if (this.state === CircuitState.HALF_OPEN) {
      this.successCount++;
      if (this.successCount >= this.config.successThreshold) {
        this.state = CircuitState.CLOSED;
        this.failureCount = 0;
      }
    } else {
      this.failureCount = 0;
    }
  }

  private onFailure(): void {
    this.failureCount++;
    this.lastFailureTime = Date.now();

    if (this.failureCount >= this.config.failureThreshold) {
      this.state = CircuitState.OPEN;
      this.nextAttempt = Date.now() + this.config.timeout;
    }
  }
}

// Usage
const paymentCircuit = new CircuitBreaker({
  failureThreshold: 5,
  successThreshold: 3,
  timeout: 30000,
  monitoringPeriod: 60000
});

async function processPayment(payment: Payment): Promise<PaymentResult> {
  return paymentCircuit.execute(async () => {
    return await paymentGateway.charge(payment);
  });
}
```

## Bulkhead Pattern

### Purpose
Isolate failures to prevent cascade. Each dependency gets its own resource pool.

### Implementation
```typescript
class Bulkhead {
  private queues: Map<string, Queue> = new Map();
  private maxConcurrent: Map<string, number> = new Map();

  constructor(config: BulkheadConfig) {
    for (const [name, limit] of Object.entries(config.limits)) {
      this.queues.set(name, new Queue(limit));
      this.maxConcurrent.set(name, limit);
    }
  }

  async execute<T>(name: string, fn: () => Promise<T>): Promise<T> {
    const queue = this.queues.get(name);
    if (!queue) throw new Error(`Bulkhead ${name} not found`);

    if (queue.size >= this.maxConcurrent.get(name)!) {
      throw new BulkheadFullError(`Bulkhead ${name} is full`);
    }

    constlease = await queue.acquire();
    try {
      return await fn();
    } finally {
      lease.release();
    }
  }
}

// Usage
const bulkhead = new Bulkhead({
  limits: {
    'database': 20,
    'external-api': 10,
    'payment-gateway': 5
  }
});

async function getUserWithBulkhead(userId: string): Promise<User> {
  return bulkhead.execute('database', async () => {
    return await prisma.user.findUnique({ where: { id: userId } });
  });
}
```

## Retry Strategies

### Exponential Backoff with Jitter
```typescript
interface RetryConfig {
  maxRetries: number;
  baseDelay: number;
  maxDelay: number;
  jitter: boolean;
  retryableErrors: string[];
}

async function retryWithBackoff<T>(
  fn: () => Promise<T>,
  config: RetryConfig
): Promise<T> {
  let lastError: Error;
  
  for (let attempt = 0; attempt <= config.maxRetries; attempt++) {
    try {
      return await fn();
    } catch (error) {
      lastError = error as Error;
      
      if (attempt === config.maxRetries) break;
      if (!config.retryableErrors.includes(lastError.name)) break;
      
      let delay = config.baseDelay * Math.pow(2, attempt);
      if (config.jitter) {
        delay = delay * (0.5 + Math.random() * 0.5);
      }
      delay = Math.min(delay, config.maxDelay);
      
      await new Promise(r => setTimeout(r, delay));
    }
  }
  
  throw lastError!;
}

// Usage
const result = await retryWithBackoff(
  () => fetch('https://api.external.com/data'),
  {
    maxRetries: 3,
    baseDelay: 1000,
    maxDelay: 10000,
    jitter: true,
    retryableErrors: ['NetworkError', 'TimeoutError', '503']
  }
);
```

### Retry with Fallback
```typescript
async function getUserWithFallback(userId: string): Promise<User> {
  try {
    // Try primary database
    return await retryWithBackoff(
      () => prisma.user.findUnique({ where: { id: userId } }),
      { maxRetries: 2, baseDelay: 500, maxDelay: 2000, jitter: true, retryableErrors: [] }
    );
  } catch (error) {
    // Fallback to read replica
    try {
      return await prismaReplica.user.findUnique({ where: { id: userId } });
    } catch (replicaError) {
      // Fallback to cache
      const cached = await redis.get(`user:${userId}`);
      if (cached) return JSON.parse(cached);
      
      throw new ServiceUnavailableError('All data sources failed');
    }
  }
}
```

## Idempotency

### Idempotency Key Pattern
```typescript
// Generate idempotency key
function generateIdempotencyKey(operation: string, params: any): string {
  const data = JSON.stringify({ operation, ...params });
  return crypto.createHash('sha256').update(data).digest('hex');
}

// Idempotent API handler
async function createAppointment(
  req: Request,
  res: Response
): Promise<void> {
  const idempotencyKey = req.headers['idempotency-key'] as string;
  
  if (!idempotencyKey) {
    return res.status(400).json({ error: 'Idempotency-Key header required' });
  }
  
  // Check if already processed
  const existing = await redis.get(`idempotency:${idempotencyKey}`);
  if (existing) {
    return res.status(200).json(JSON.parse(existing));
  }
  
  // Process request
  const appointment = await appointmentService.create(req.body);
  
  // Store result with TTL (24 hours)
  await redis.setex(
    `idempotency:${idempotencyKey}`,
    86400,
    JSON.stringify(appointment)
  );
  
  return res.status(201).json(appointment);
}
```

### Database Idempotency
```sql
-- Idempotent insert using ON CONFLICT
INSERT INTO appointments (id, clinic_id, patient_id, scheduled_at, status)
VALUES ($1, $2, $3, $4, 'scheduled')
ON CONFLICT (id) DO NOTHING;

-- Idempotent update using version check
UPDATE appointments 
SET status = 'confirmed', version = version + 1
WHERE id = $1 AND version = $2
RETURNING *;
```

## Timeout Patterns

### Per-Operation Timeouts
```typescript
async function fetchWithTimeout<T>(
  url: string,
  options: RequestInit,
  timeoutMs: number
): Promise<T> {
  const controller = new AbortController();
  const timeoutId = setTimeout(() => controller.abort(), timeoutMs);
  
  try {
    const response = await fetch(url, {
      ...options,
      signal: controller.signal
    });
    
    if (!response.ok) {
      throw new Error(`HTTP ${response.status}`);
    }
    
    return await response.json();
  } finally {
    clearTimeout(timeoutId);
  }
}

// Usage
const user = await fetchWithTimeout(
  'https://api.external.com/user/123',
  { method: 'GET' },
  5000 // 5 second timeout
);
```

### Cascading Timeouts
```typescript
// Total timeout for entire operation
async function getUserWithAppointments(userId: string): Promise<UserWithAppointments> {
  return withTimeout(async () => {
    const user = await getUser(userId); // 2s timeout
    const appointments = await getAppointments(userId); // 3s timeout
    
    return { user, appointments };
  }, 5000); // Total 5s timeout
}

function withTimeout<T>(fn: () => Promise<T>, timeoutMs: number): Promise<T> {
  return Promise.race([
    fn(),
    new Promise<never>((_, reject) => 
      setTimeout(() => reject(new TimeoutError('Operation timed out')), timeoutMs)
    )
  ]);
}
```

## Health Checks

### Deep Health Check
```typescript
async function healthCheck(): Promise<HealthStatus> {
  const checks = await Promise.allSettled([
    // Database
    prisma.$queryRaw`SELECT 1`,
    
    // Redis
    redis.ping(),
    
    // External API
    fetch('https://api.external.com/health'),
    
    // Disk space
    checkDiskSpace()
  ]);
  
  const results = checks.map((check, index) => ({
    name: ['database', 'redis', 'external-api', 'disk'][index],
    status: check.status === 'fulfilled' ? 'healthy' : 'unhealthy',
    error: check.status === 'rejected' ? check.reason.message : undefined
  }));
  
  const isHealthy = results.every(r => r.status === 'healthy');
  
  return {
    status: isHealthy ? 'healthy' : 'degraded',
    timestamp: new Date().toISOString(),
    checks: results
  };
}
```

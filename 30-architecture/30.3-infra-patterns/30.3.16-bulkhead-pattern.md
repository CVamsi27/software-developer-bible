# Bulkhead Pattern

> **Isolating failures by partitioning resources — preventing one bad component from sinking the whole system.**

---

## The Metaphor

Ships have bulkheads — watertight compartments that prevent a hull breach in one section from flooding the entire ship. In software, bulkheads isolate resources (threads, connections, memory) so a failure in one service doesn't consume all resources.

```
Without Bulkhead:
┌─────────────────────────────────────┐
│           Shared Thread Pool          │
│  ┌──────────┐  ┌──────────┐         │
│  │ Payment   │  │ Search   │  ← Slow│
│  │ Service   │  │ Service  │  query │
│  │ (fast)    │  │ (slow)   │  uses  │
│  │           │  │          │  ALL   │
│  │ ⏳ waits  │  │ 💀 all   │  threads│
│  └──────────┘  └──────────┘         │
└─────────────────────────────────────┘

With Bulkhead:
┌──────────────────┐  ┌──────────────────┐
│ Payment Bulkhead  │  │ Search Bulkhead   │
│ (10 threads)      │  │ (10 threads)      │
│ ┌──────┐          │  │ ┌──────┐          │
│ │✅ ✅ │          │  │ │💀 💀 │ ← Slow  │
│ │✅ ✅ │          │  │ │💀 💀 │  query  │
│ └──────┘          │  │ └──────┘          │
│ Payment works! ✅ │  │ Only search fails │
└──────────────────┘  └──────────────────┘
```

## Implementation

### NestJS with Resilience4j-style Bulkhead

```typescript
// bulkhead.provider.ts
import { Injectable } from '@nestjs/common';

@Injectable()
export class BulkheadProvider {
  private bulkheads = new Map<string, BulkheadState>();

  getBulkhead(name: string, maxConcurrent: number): BulkheadState {
    if (!this.bulkheads.has(name)) {
      this.bulkheads.set(name, {
        name,
        maxConcurrent,
        currentConcurrent: 0,
        queue: [],
      });
    }
    return this.bulkheads.get(name)!;
  }

  async execute<T>(
    bulkheadName: string,
    maxConcurrent: number,
    fn: () => Promise<T>
  ): Promise<T> {
    const bulkhead = this.getBulkhead(bulkheadName, maxConcurrent);

    if (bulkhead.currentConcurrent >= bulkhead.maxConcurrent) {
      throw new Error(`Bulkhead ${bulkheadName} is full`);
    }

    bulkhead.currentConcurrent++;
    try {
      return await fn();
    } finally {
      bulkhead.currentConcurrent--;
    }
  }
}

// Usage in service
@Injectable()
export class PaymentService {
  constructor(private bulkhead: BulkheadProvider) {}

  async processPayment(payment: Payment) {
    // Isolated: only 5 concurrent payments allowed
    return this.bulkhead.execute('payment', 5, async () => {
      return this.stripeClient.charges.create({
        amount: payment.amount,
        currency: 'eur',
      });
    });
  }
}

@Injectable()
export class SearchService {
  constructor(private bulkhead: BulkheadProvider) {}

  async searchPatients(query: string) {
    // Isolated: only 10 concurrent searches allowed
    return this.bulkhead.execute('search', 10, async () => {
      return this.elasticsearch.search({
        index: 'patients',
        body: { query: { match: { name: query } } },
      });
    });
  }
}
```

## Bulkhead Configurations

| Resource | Strategy | Config |
|----------|----------|--------|
| **Thread pool** | Fixed pool per service | Payment: 10, Search: 20 |
| **Connection pool** | Max connections per downstream | Database: 10, Redis: 5 |
| **Semaphore** | Max concurrent executions | API: 100, Worker: 5 |
| **Timeout** | Max wait time in queue | 5 seconds, then reject |

## Bulkhead + Circuit Breaker Combo

```typescript
class ResilientClient {
  private circuitBreakers = new Map<string, CircuitBreaker>();
  private bulkheads = new Map<string, BulkheadState>();

  async call<T>(
    serviceName: string,
    fn: () => Promise<T>,
    options: { maxConcurrent: number; timeoutMs: number }
  ): Promise<T> {
    // Layer 1: Circuit breaker — stop calling if service is down
    const cb = this.getCircuitBreaker(serviceName);
    if (cb.state === 'open') {
      throw new Error(`Circuit open for ${serviceName}`);
    }

    // Layer 2: Bulkhead — limit concurrent calls
    const bh = this.getBulkhead(serviceName, options.maxConcurrent);
    if (bh.current >= bh.max) {
      throw new Error(`Bulkhead full for ${serviceName}`);
    }

    // Layer 3: Timeout — don't wait forever
    return Promise.race([
      fn(),
      new Promise((_, reject) =>
        setTimeout(() => reject(new Error('Timeout')), options.timeoutMs)
      ),
    ]);
  }
}
```

## When to Use Bulkhead

| Scenario | Bulkhead Config | Why |
|----------|-----------------|-----|
| **Payment processing** | 5-10 concurrent | Prevent payment failures from blocking other services |
| **File uploads** | 3-5 concurrent | Large files consume resources |
| **External API calls** | Per-service pool | One slow API shouldn't block others |
| **Database queries** | Connection pool | Prevent slow queries from exhausting connections |
| **Report generation** | Dedicated pool | CPU-intensive reports don't block API |

## Interview Questions

**Q: "How do you prevent a slow service from affecting others?"**

> Bulkhead pattern: isolate each downstream service into its own resource pool (threads, connections, semaphores). If the search service is slow, it only exhausts its own 10-thread pool — payment service still has its 5-thread pool available. Combine with circuit breaker: if search fails 50% of times in 10s, circuit opens and all requests fail fast without consuming any resources. This prevents cascading failures across services.

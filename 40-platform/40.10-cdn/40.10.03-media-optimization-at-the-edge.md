# Media Optimization at the Edge

> Images and video dominate page weight and egress bills. Modern CDNs transform media **at the edge** — resizing images on the fly, negotiating AVIF/WebP, packaging video into adaptive ladders — so each device gets exactly what it can use, nothing more.

## Definition

**Media optimization at the edge** is the practice of letting CDN infrastructure derive per-request variants of images and video from canonical originals:

| Capability             | What it does                                                          | Typical surface                   |
| ---------------------- | --------------------------------------------------------------------- | --------------------------------- |
| **Image CDN**          | On-the-fly resize/crop/format/quality via URL params or edge function | `/cdn-cgi/image/w=640,f=avif/...` |
| **Format negotiation** | Serve AVIF/WebP when `Accept` allows; JPEG/PNG fallback               | `Vary: Accept`                    |
| **Video packaging**    | Encode one mezzanine into HLS/DASH ladders; players switch bitrate    | `.m3u8`, `.mpd` manifests         |
| **Origin shield**      | Middle tier that collapses misses before they hit origin              | shield PoP config                 |
| **Signed URLs**        | Time-boxed HMAC tokens preventing hotlinking/leeching                 | `?exp=...&sig=...`                |

```text
REQUEST-TIME IMAGE PIPELINE (image CDN)

GET /img/hero.jpg?w=420&f=auto&q=80
        │
   cache HIT? ──yes──► serve stored variant
        │ no
        ▼
edge worker: parse params → fetch ORIGINAL once
             → decode → resize 420w → encode AVIF (Accept says ok)
             → store under transformation cache key → serve
```

## Why Do We Need It?

1. **Images are ~40-50% of median page bytes** — right-sizing them is the largest single web-performance lever.
2. **Device zoo** — one original must serve watches through 5K displays; pre-generating every variant does not scale.
3. **Next-gen codecs pay instantly** — AVIF typically saves 30-50% over JPEG at equal quality, directly improving LCP.
4. **Video without ABR is unusable on mobile networks** — adaptive ladders keep playback smooth across bandwidth swings.
5. **Origin protection** — transforms and shields mean origin stores one file and serves a fraction of requests.
6. **Cost control** — media is most of the egress bill; format choice and caching policy move real money.

## How It Works

### Image CDNs: Transform On-the-Fly

Every provider exposes transformation parameters (Cloudflare Image Resizing, Cloudinary, imgix, Akamai Image Manager, Next.js image optimization):

```text
URL-driven contract:
  /cdn-cgi/image/width=800,height=450,fit=cover,format=auto,quality=80/shop/hero.jpg
                              │
        format=auto ──► inspect request Accept header:
                          includes image/avif → AVIF
                          else image/webp     → WebP
                          else                → original codec
```

Key transformations: width/height + fit mode (`cover` crops, `contain` pads), DPR variants for retina, smart cropping ( saliency/faces), compression quality, and chroma subsampling.

### Format Negotiation Done Right

```text
Client sends:      Accept: image/avif,image/webp,image/*,*/*
CDN must respond:  Vary: Accept        ← CRITICAL: otherwise caches conflate formats

Cache key = normalized URL + selected format bucket
  key(hero.jpg) = /img/hero.jpg|w=420|fmt=avif
```

Forgetting `Vary: Accept` (or an equivalent key rule) is the classic bug: first visitor's format gets cached for everyone.

### Video Packaging: HLS/DASH and ABR Ladders

One high-quality mezzanine file is encoded into a ladder of renditions; players adapt segment-by-segment:

```text
MEZZANINE (prores 4K master)
   │ encoder (e.g., per-title encoding)
   ▼
renditions:  2160p @ 16 Mbps │ 1080p @ 8 Mbps │ 720p @ 4.5 Mbps │ 480p @ 2 Mbps │ 360p @ 0.8 Mbps
   │ each split into 2-6s segments (fMP4/CMAF — same segments serve HLS AND DASH)
   ▼
manifest:  index.m3u8 (HLS)          manifest.mpd (DASH)
           player picks rendition by measured bandwidth + buffer health
```

- **ABR ladder**: resolution/bitrate rungs; per-title encoding tunes rungs to content complexity (cartoons need fewer bits than sports).
- **LL-HLS/LL-DASH**: ~2-4s latency via smaller parts and blocking playlist reloads for live.
- Codecs: H.264 baseline compatibility, HEVC/AV1 as higher-efficiency rungs with fallback chains.

### Origin-Shield Patterns for Media

```text
WITHOUT SHIELD                         WITH SHIELD
edge miss #1 ──► origin                edge misses (many edges) ──► shield PoP
edge miss #2 ──► origin  ◄ stampede    shield: 1 request to origin,
edge miss #3 ──► origin                others collapse/wait at shield

benefits: origin QPS ∝ edges→shield misses collapsed to ~1
costs:    extra hop adds ms; shield egress billed by some vendors
```

Shield placement matters for media: pick shield regions near origin (e.g., US-East for a US-East origin) and enable request coalescing so concurrent misses share one origin fetch.

### Signed URLs & Hotlink Protection

```typescript
// Origin/worker signs time-boxed media URLs
import { createHmac } from 'node:crypto';

export function signUrl(path: string, ttlSeconds = 300): string {
  const exp = Math.floor(Date.now() / 1000) + ttlSeconds;
  const sig = createHmac('sha256', process.env.MEDIA_SIGNING_KEY!)
    .update(`${path}:${exp}`)
    .digest('base64url');
  return `${path}?exp=${exp}&sig=${sig}`;
}

// CDN edge (Worker) verifies before serving
export async function verify(request: Request): Promise<Response> {
  const url = new URL(request.url);
  const exp = Number(url.searchParams.get('exp'));
  const sig = url.searchParams.get('sig') ?? '';
  if (!exp || exp < Date.now() / 1000) return new Response('expired', { status: 403 });

  const expected = createHmac('sha256', SIGNING_KEY)
    .update(`${url.pathname}:${exp}`)
    .digest('base64url');
  if (!timingSafeEqual(sig, expected)) return new Response('forbidden', { status: 403 });

  // IMPORTANT: strip query before cache lookup OR include only sig-free parts in key
  return fetch(new URL(url.pathname, url.origin), { cf: { cacheEverything: true } });
}
```

Layered protections: signed URLs (primary), Referer/origin allowlists (weak alone — spoofable), CORS rules for cross-origin embeds, rate limits per token/IP.

### Cache Keys for Transformations

The cache key must capture every input that changes output:

```text
key components:
  • canonical source path            /img/hero.jpg
  • every transformation param       w,h,fit,q,dpr,bg
  • resolved format                  avif | webp | jpeg
  • relevant client hints            Save-Data, DPR (Sec-CH-DPR)

normalization rules:
  • order params canonically         ?q=80&w=400 ≡ ?w=400&q=80
  • drop tracking junk               utm_*, fbclid never in key
  • cap variant explosion            round widths to buckets (320/480/640/...)
```

Unbounded parameter combos are the DoS vector for image CDNs: restrict allowed params and bucket sizes, or attackers generate infinite cache entries (and origin fetches).

### Cost Levers

| Lever                        | Action                                                                                   | Impact                                 |
| ---------------------------- | ---------------------------------------------------------------------------------------- | -------------------------------------- |
| Codec selection              | prefer AVIF/WebP where supported                                                         | 20-50% byte cut                        |
| Quality tuning               | q=75-85 sweet spot vs q=100 defaults                                                     | large savings, invisible visually      |
| Variant capping              | bucketed widths/DPR instead of exact                                                     | fewer unique objects, higher hit ratio |
| TTL strategy                 | long immutable TTLs on transformed assets                                                | offload ↑, origin ↓                    |
| Pre-generation vs on-the-fly | pre-render top-N hero images; long-tail stays lazy                                       | predictable cost for hot paths         |
| Egress mix                   | vendor rates differ per region (see [Multi-CDN](40.10.02-multi-cdn-traffic-steering.md)) | arbitrage heavy media traffic          |

## Code Examples

### Edge Worker Image Pipeline With Negotiation and Key Normalization

```typescript
interface ImgParams {
  width: number;
  quality: number;
  format: 'avif' | 'webp' | 'jpeg';
}

const WIDTH_BUCKETS = [320, 480, 640, 960, 1280, 1920];

function pickWidth(requested: number | null): number {
  if (!requested) return 960;
  return WIDTH_BUCKETS.find((b) => b >= requested) ?? WIDTH_BUCKETS.at(-1)!;
}

function negotiate(accept: string | null): ImgParams['format'] {
  if (accept?.includes('image/avif')) return 'avif';
  if (accept?.includes('image/webp')) return 'webp';
  return 'jpeg';
}

export function cacheKeyFor(url: URL, accept: string | null): string {
  const p = new URLSearchParams(url.search);
  const key = [
    url.pathname,
    pickWidth(Number(p.get('w'))),
    p.get('q') ?? '80',
    negotiate(accept),
  ].join('|');
  return key;                      // deterministic, bucketed, format-aware
}

export default {
  async fetch(request: Request, env: Env): Promise<Response> {
    const url = new URL(request.url);
    if (!url.pathname.startsWith('/img/')) return fetch(request);

    const accept = request.headers.get('accept');
    const cacheKey = cacheKeyFor(url, accept);
    const cached = await env.MEDIA_CACHE.get(cacheKey, { type: 'arrayBuffer' });
    if (cached) {
      return new Response(cached, {
        headers: {
          'content-type': `image/${cacheKey.split('|').at(-1)}`,
          'cache-control': 'public, max-age=31536000, immutable',
          vary: 'Accept',
        },
      });
    }

    const transformed = await fetch(
      `https://images.example.com/render${url.pathname}` +
      `?w=${cacheKey.split('|')[1]}&q=${cacheKey.split('|')[2]}&f=${cacheKey.split('|')[3]}`
    );
    await env.MEDIA_CACHE.put(cacheKey, await transformed.clone().arrayBuffer());
    return transformed;
  },
};
```

### HLS Playback Wiring (hls.js)

```typescript
import Hls from 'hls.js';

export function attachPlayer(video: HTMLVideoElement, src: string): void {
  if (video.canPlayType('application/vnd.apple.mpegurl')) {
    video.src = src;                       // Safari native HLS
    return;
  }
  if (Hls.isSupported()) {
    const hls = new Hls({ startLevel: 1 }); // start conservative, ramp up
    hls.loadSource(src);
    hls.attachMedia(video);
  }
}
```

## Real-World Use Cases

### 1. Marketplace With Millions of Product Photos

Sellers upload originals once; image CDN derives thumbnails, cards, and zoom variants per device class. Bucketed widths keep the variant space finite; AVIF cuts mobile data plans and LCP simultaneously.

### 2. News Site Breaking-Event Traffic

Hero imagery pre-transformed and pinned with immutable caching; article pages reference stable hashed URLs; origin sees almost nothing during traffic spikes because shields hold the top set.

### 3. Streaming Course Platform

Per-title ABR ladders maximize quality within student bandwidth; signed URLs expire after session windows preventing credential sharing; CMAF packaging serves both iOS (HLS) and Android/web (DASH) from one segment store.

### 4. UGC Social App Hotlink Defense

Signed, short-TTL URLs plus referer checks stop competitor apps embedding user media; edge rate limits blunt scraping attempts against transformation endpoints.

### 5. Global Retailer Egress Reduction Program

Audit shows images are 70% of CDN bill. Actions: WebP/AVIF negotiation, quality retuning, width bucketing, and shifting APAC traffic to cheaper vendor — combined 38% egress reduction in one quarter.

## Common Mistakes

### 1. Missing Vary: Accept (or Equivalent Key Rule)

Without format in the cache key/Vary, one visitor's AVIF gets served as everyone's response — older browsers break subtly. Always bind format into the key.

### 2. Unbounded Transformation Parameters

```bash
# Bad: attacker crawls ?w=<anything>&q=<anything> creating infinite cache entries
# Good: whitelist params, bucket values, reject unknown combos at the edge
```

### 3. Signing URLs but Caching Including the Signature

If `sig` lands in the cache key, every user generates their own cache entry (hit ratio collapses). Strip signature params before lookup, or sign path+expiry only.

### 4. One Giant Rung Ladder for All Content

A static 5-rung ladder wastes bits on cartoons and starves sports footage. Use per-title/content-aware encoding for anything with meaningful view hours.

### 5. Forgetting Dimensions on `<img>` (CLS)

Responsive images without `width`/`height` attributes cause layout shift as media loads — negating perf wins at the Core-Web-Vitals scorecard.

### 6. Shield Misconfiguration

Enabling shields far from origin doubles hop latency; disabling coalescing lets stampedes through anyway. Place shields near origin and verify request-collapsing behavior during load tests.

## Best Practices

1. **Store pristine originals** at maximum sensible resolution; treat every derivative as disposable.
2. **Negotiate formats server-side** (AVIF → WebP → legacy) with format bound into cache identity.
3. **Bucket dimensions and qualities** to keep the variant universe small and hit ratios high.
4. **Set long immutable TTLs** on transformed media; invalidate via versioned URLs rather than purges.
5. **Protect everything valuable**: signed URLs for private media, referer+CORS for public embeds, rate limits everywhere.
6. **Adopt CMAF** so one segment store feeds HLS and DASH.
7. **Measure with RUM**: track LCP and rebuffer ratio per format/ladder changes (see [Multi-CDN measurement](40.10.02-multi-cdn-traffic-steering.md)).
8. **Review media costs quarterly** — codec defaults and vendor pricing both drift.

## Performance Considerations

| Factor                       | Effect                                  | Tuning                                      |
| ---------------------------- | --------------------------------------- | ------------------------------------------- |
| On-the-fly transform latency | cold misses add 100-500ms               | pre-warm top assets; async fill pattern     |
| Variant explosion            | memory/cache pressure, low hits         | bucketing + param whitelists                |
| AVIF encoding CPU            | slower than WebP                        | reserve AVIF for above-fold; WebP elsewhere |
| Segment size (video)         | smaller = faster startup, more overhead | 2-4s CMAF; LL-HLS parts for live            |
| Shield hops                  | +latency per miss                       | shield near origin; coalescing on           |

## Summary

- Image CDNs derive per-request variants (size, crop, format, quality) from single originals — the biggest page-weight lever available.
- Format negotiation requires binding the chosen format into cache identity (`Vary: Accept` or key rules) or caches poison each other.
- Video ships as HLS/DASH ABR ladders from one mezzanine; CMAF unifies packaging; per-title encoding optimizes ladders per content.
- Origin shields collapse concurrent misses and protect origin during spikes and failovers — place near origin, enable coalescing.
- Signed URLs with expiry plus referer/CORS/rate-limit layers defend against hotlinking and scraping; keep signatures out of cache keys.
- Cost control = codec choice + quality tuning + variant bucketing + TTL/offload discipline + regional egress arbitrage.

════════════════════════════════════════════════════

IMAGE PIPELINE:
  original (pristine) → edge transforms on demand

VIDEO PACKAGING:
  mezzanine → ABR ladder (per-title tuned)

  player: startLevel conservative, ramp by bandwidth

ORIGIN SHIELD:
  edges → shield PoP (near origin) → origin
  request collapsing/coalescing ON
  prevents stampede on cold cache + failover

PROTECTION:
  signed URLs = HMAC(path:exp), short TTL

  referer allowlists weak-alone; CORS + rate limits layer up

COST LEVERS:
  AVIF/WebP adoption        quality retune (not q=100)
  variant bucketing         immutable long TTLs
  pre-generate hot paths    egress region arbitrage

  • Say "format must be part of the cache key" unprompted
  • Draw shield collapsing N edge misses to 1
  • Tie media work to LCP + egress $ outcomes

## How to use this bank

The 30 questions cover workloads, networking, configuration, scaling, reliability, security, packaging, and delivery. Answer aloud before reading each explanation. State assumptions, trace the mechanism, then name a failure mode and a verification step. Use the linked chapter when an answer depends on a specific Application Programming Interface (API) or controller behavior.

## Docita Anchor

Where [docita](https://github.com/CVamsi27/docita) meets this topic.

_No direct docita implementation yet._ Docita's candidate Fly.io configuration provides comparisons to study: health checks and scaling settings can be compared with readiness and Horizontal Pod Autoscaler (HPA) ownership, while Row-Level Security (RLS) and Attribute-Based Access Control (ABAC) address application data and access controls. Configuration alone does not establish deployed behavior or production experience. Keep these application and platform analogies separate from Kubernetes admission and network policy, and state the cluster evidence actually available.

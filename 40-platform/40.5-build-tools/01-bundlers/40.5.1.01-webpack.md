# Webpack

## Definition

Webpack follows imports from an entry module and produces deployable JavaScript chunks and related assets. A loader transforms one module's source; a plugin participates in the broader compilation lifecycle.

> **Textbook Definition:** webpack is a static module bundler that constructs dependency graphs, applies configured transformations and emits assets with generated runtime loading behavior.

## First Principles

A browser supports native ES modules, CSS and images, but TypeScript/JSX and CommonJS often need transformation or interoperation. Many separate imports also create loading and caching choices. A build therefore has to resolve dependencies, transform unsupported inputs and choose which outputs load together. Those are separate steps: combining modules does not itself make them compatible or small.

## Why It Matters

Webpack's extension model supports applications with custom loaders, plugins and federation needs. It also supports incremental watch builds and filesystem caching; it does not rebuild every module from scratch after every edit. Compatibility and configuration costs matter alongside speed.

## How the Graph Becomes Chunks

```text
entry → resolve imports → load/transform modules → analyze graph
      → choose chunks and optimize → emit runtime + assets
```

Loaders usually run right to left in the normal transform chain, so `style-loader` receives JavaScript produced by `css-loader`, not raw CSS. Plugins can operate at many stages, not just one final optimization step. Asset modules handle resources without legacy `file-loader`/`url-loader` setup.

Static ESM imports make export use analyzable. `sideEffects` separately declares whether evaluating a module can be omitted. Never mark an entire package false if imports register handlers, modify globals or load required CSS. Production minimization performs further removal; inspect the emitted result instead of assuming every unused export disappears.

## Example: A Complete Lazy Chunk

In a disposable directory, install `webpack` and `webpack-cli`. Save these files:

```javascript
// src/index.js
console.log('entry loaded');
globalThis.loadFeature = () => import('./feature.js').then(m => m.answer());
```

```javascript
// src/feature.js
export const answer = () => 42;
```

```javascript
// webpack.config.cjs
const path = require('node:path');
module.exports = {
  mode: 'production',
  entry: './src/index.js',
  output: {
    path: path.resolve(__dirname, 'dist'),
    filename: 'main.[contenthash].js',
    chunkFilename: '[name].[contenthash].js',
    publicPath: 'auto',
    clean: true,
  },
  cache: { type: 'filesystem' },
};
```

```bash
npx webpack --config webpack.config.cjs
```

The main file installs `loadFeature`; the feature is emitted as a separate chunk. Serve the emitted files over HTTP and include the main filename in HTML. Calling `loadFeature()` then requests the chunk. `publicPath: 'auto'` derives the asset base from runtime context; subpath/CDN deployments still need verification.

Changing a feature changes its content identity. Rebuilding unchanged inputs should preserve filenames under the same toolchain, but deterministic output also depends on environment/configuration. Retain old chunks during deployments because an already-open browser can still request them.

## Real-World Decisions

Use CSS extraction for production when separate stylesheet caching suits the application; `style-loader` injects styles at runtime and has a different loading/CSP contract. Babel/SWC/TypeScript loaders handle syntax, while explicit type checking verifies types. Excluding `node_modules` from a loader avoids transforming dependencies; it does not exclude imported dependencies from the bundle.

For federation, a host loads a remote container and negotiates shared dependencies. Singleton configuration is not proof of compatible versions or a fallback on network failure. Plan remote trust, release coordination, CSP, timeouts and failure UI.

## Mistakes and Best Practices

Set mode explicitly; use bounded split rules informed by route measurements. Giant vendor chunks and excessive microchunks both have costs. `DefinePlugin` substitutes values at build time and can expose secrets to clients; it does not automatically read a `.env` file. Persistent caches need configuration/toolchain dependencies and correct CI restoration. Diagnose transform cost before adding worker pools: startup and serialization can outweigh savings.

## Summary

Webpack resolves and transforms modules, then emits chunks with a runtime loading contract. Distinguish loaders from plugins, export pruning from side-effect preservation, and content identity from deployment availability. Validate the emitted application under its actual hosting paths.

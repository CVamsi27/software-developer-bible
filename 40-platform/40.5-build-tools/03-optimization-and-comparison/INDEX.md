## Why this category exists

Tool choice gets debated endlessly; bundle size regressions ship silently. This category covers the mechanics that apply to every bundler (tree shaking, route-level code splitting, source maps, build caches) and a side-by-side comparison so you can justify the pick — the form senior interviews reward.

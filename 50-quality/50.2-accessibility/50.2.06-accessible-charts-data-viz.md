# Accessible Charts & Data Visualization

A revenue chart lets a sighted reader compare quarters in seconds. Someone reading a table needs the values and units; someone listening may first need the main trend before choosing which values to inspect. Preserve both insight and precision.

```text
                 one authoritative dataset
                 /          |           \
        trend summary    visual chart   exact table
                             |
                  any interaction has an equivalent operable path
```

## Definition

**Accessible data visualization** makes a chart's information and interactions available through meaningful visual cues, **text** and **structured data**, plus usable input paths. A chart title identifies the subject; it rarely supplies every value or relationship the task requires.

> **Textbook Definition:** Accessible data visualization provides equivalent access to a chart's information and interactions through perceptible encodings, text or structured data alternatives, and operable controls.

## First Principles

A graphic compresses data into position, length, color and shape — and rendered pixels do not by themselves explain those relationships through a nonvisual path. Expose the same underlying information in an appropriate alternative, and keep it consistent when data or filters change. Static information and operable controls carry different contracts: treating a whole chart as one image-like object suits a static summary but conceals independently operable descendants.

## How It Works

### 1. Connect Summary, Graphic and Exact Values

A short alternative identifies the chart; a longer explanation supplies relevant relationships, units and caveats; a table makes exact values available. Choose detail from the task: a table alone may leave an important trend hard to find, while a trend sentence alone cannot answer an exact-value question. [W3C complex-image guidance](https://www.w3.org/WAI/tutorials/images/complex/).

### 2. Generate a Static Chart and Table From the Same Data

Save this complete fixture as `revenue.html`. It presents synthetic quarterly revenue in euros with a zero-baseline bar chart. The SVG is one named static graphic; the HTML summary and data disclosure remain separately readable.

```html
<!doctype html>
<html lang="en">
<meta charset="utf-8">
<title>Quarterly revenue and data</title>
<style>
  body { color: #1a1a1a; background: white; }
  svg { display: block; width: min(100%, 28rem); height: auto; }
  :focus-visible { outline: 3px solid #005fcc; outline-offset: 3px; }
  th, td { padding: .4rem; text-align: left; }
</style>
<main>
  <h1>Quarterly revenue, 2025</h1>
  <figure>
    <svg id="revenue-chart" role="img" aria-labelledby="revenue-title"
         aria-describedby="revenue-summary" viewBox="0 0 420 280">
      <title id="revenue-title">Bar chart of quarterly revenue in euros</title>
      <g id="revenue-bars" aria-hidden="true"></g>
    </svg>
    <figcaption>Quarterly revenue, 2025 (EUR)</figcaption>
  </figure>
  <p id="revenue-summary"></p>
  <details>
    <summary>View exact revenue data</summary>
    <table>
      <caption>Quarterly revenue, 2025, in euros</caption>
      <thead><tr><th scope="col">Quarter</th><th scope="col">Revenue (EUR)</th></tr></thead>
      <tbody id="revenue-rows"></tbody>
    </table>
  </details>
</main>
<script>
  const data = [
    { quarter: 'Q1', revenue: 1_200_000 },
    { quarter: 'Q2', revenue: 1_500_000 },
    { quarter: 'Q3', revenue: 1_400_000 },
    { quarter: 'Q4', revenue: 1_900_000 },
  ];
  const euros = new Intl.NumberFormat('en-IE');
  const bars = document.getElementById('revenue-bars');
  const rows = document.getElementById('revenue-rows');
  const ns = 'http://www.w3.org/2000/svg';
  const maximum = Math.max(...data.map(item => item.revenue));
  const graphic = (tag, attrs, text) => {
    const node = document.createElementNS(ns, tag);
    for (const [key, value] of Object.entries(attrs)) node.setAttribute(key, String(value));
    if (text !== undefined) node.textContent = text;
    bars.append(node);
  };
  data.forEach((item, index) => {
    const x = 20 + index * 100;
    const height = 190 * item.revenue / maximum;
    graphic('rect', { x, y: 230 - height, width: 65, height, fill: '#1e40af' });
    graphic('text', { x, y: 250, fill: '#1a1a1a' }, item.quarter);
    graphic('text', { x, y: 220 - height, fill: '#1a1a1a' }, `${item.revenue / 1_000_000}M`);
    const row = document.createElement('tr');
    const quarter = document.createElement('th');
    quarter.scope = 'row'; quarter.textContent = item.quarter;
    const value = document.createElement('td');
    value.textContent = euros.format(item.revenue);
    row.append(quarter, value); rows.append(row);
  });
  const growth = 100 * (data[3].revenue - data[0].revenue) / data[0].revenue;
  document.getElementById('revenue-summary').textContent =
    `Revenue increased ${growth.toFixed(1)}% from Q1 to Q4, with a dip in Q3. ` +
    'The data disclosure contains all four exact euro values. M means million euros.';
</script>
</html>
```

The same array supplies bar heights, visible labels and table cells: Q1→Q4 rises 700,000/1,200,000 (approximately 58.3%), with Q3 below Q2. The summary exposes that relationship and explains the shortened unit. Enter or Space operates the native `details` disclosure, and the table's column and row headers support exact-value inspection.

The fixture is deliberately fixed to four positive quarters. Empty data, negative values, other units, loading and failure states, and changing filters need explicit rendering and summary rules — and a data alternative must never silently retain an old filter while the graphic changes. Its white theme and text/mark pairs also need evaluation before adapting them to another surface.

### 3. Preserve Meaning With More Than One Series

For one series, bar height and labeled quarter carry the comparison and color is decoration. With several categories or statuses, hue alone may be the only distinguishing cue — add direct labels, line dashes, markers or textures, and check their clarity at the shown density. A luminance ramp can convey ordered magnitude but does not make every heatmap universally distinguishable; include values or an equivalent structured path where needed. Measure the visual information required to interpret the graphic against relevant adjacent colors, using the [contrast chapter](50.2.04-color-and-contrast.md).

### 4. Let Interaction Survive a Different Input Path

A pointer-hover tooltip cannot be the only way to read a value. If points are interactive, define how keyboard focus reaches them, how values appear on focus, and how the user exits the widget — hover and focus content also needs a way to dismiss it, reach it where necessary, and keep it visible while in use. Dense datasets do not require one Tab stop per point: a scoped arrow-navigation model, a sortable and filterable table, or a labeled selection control can supply a clearer path.

Preserve equivalents for selecting a range, filtering, drilling into a point and resetting; an alternative listing only values may omit the chart's actionable tasks. If a point navigates or acts, give it the corresponding link or button semantics — `role="listitem"` alone supplies neither action nor a complete interaction model, and controls must not hide as children of an atomic `role="img"` wrapper. For live data, retain a readable snapshot or pause mechanism, and offer summaries without announcing every sample. **Sonification** maps data to sound, such as pitch changing with magnitude: it can reveal shape but needs explained mappings, controls and an exact-data path. Avoid autoplay.

### 5. Check the Library Model and Choose the Alternative From the Task

Recharts 3 enables its `accessibilityLayer` prop by default, adding a chart focus target and arrow-key navigation. That helps with dense data, but the library cannot supply the product explanation, the exact-value alternative or every task — test the pinned version with supported browser and screen-reader combinations. [Recharts accessibility documentation](https://github.com/recharts/recharts/blob/main/storybook/stories/API/Accessibility.mdx).

Start from the information and tasks: exact comparison, trend, uncertainty, selection or live status. A compact static graphic may need only a named summary and table; a complex financial dashboard may need several navigable views and a stable alternative to animated updates. Downloads can help analysts, but an HTML alternative keeps the task within the page for people who cannot conveniently use the file format. Never claim that a library, label or downloadable file alone establishes access to every task.

## Summary

A chart's alternative preserves the information and tasks it encodes. Combine an informative summary with precise structured data, non-color distinctions and usable interactions. Keep those views synchronized from one dataset, and evaluate actual library behavior rather than relying on a name or role alone.

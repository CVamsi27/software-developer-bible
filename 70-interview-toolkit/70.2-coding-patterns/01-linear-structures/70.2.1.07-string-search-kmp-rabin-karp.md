# String Search — KMP & Rabin-Karp

In `ABABABAC`, matching `ABABAC` fails after five characters. KMP keeps the overlapping `ABA` prefix instead of restarting the search at the next text position.

```typescript
strStr("sadbutsad", "sad"); // 0 — first occurrence without rescanning
```

## Definition

**String search** finds occurrences of a **pattern** `P` (length `m`) inside a **text** `T` (length `n`); naive search is O(nm). **Knuth-Morris-Pratt (KMP)** builds a **failure function** (prefix function, or LPS — longest proper prefix which is also a suffix) in O(m) time, then searches in O(n) — total **O(n+m)** with O(m) space. **Rabin-Karp** uses a **rolling hash** to compute every length-m window hash in O(1) per shift, then verifies each hash match in O(m).

> **Textbook Definition:** String matching locates a pattern within text. KMP reuses prefix-suffix relationships to avoid repeated comparisons; Rabin-Karp filters candidate matches with rolling hashes and requires collision handling.

## First Principles

Naive string search is O(nm) because a mismatch wastes all alignment progress. KMP's insight: the pattern knows its own overlaps — the failure function records the longest proper prefix-suffix, so after a mismatch you shift by *knowledge*, not by 1, and the text pointer never moves backward. Rabin-Karp's insight: fingerprints compare in O(1) — rolling hash updates the window in constant time, so compare hashes and verify only on match. That suits multi-pattern search; the collision risk is why verification stays.

## Why It Matters

String search serves **DNA and protein matching, plagiarism detection, log analysis, and grep-style searching**. The senior-level questions are **deriving the KMP failure function** (the LPS array is the heart of the algorithm), **handling hash collisions in Rabin-Karp** (always verify actual characters on a hash match), and **choosing between KMP and Rabin-Karp** by use case. A naive baseline is useful for checking small examples; improve it only when input bounds require the additional machinery.

## How It Works

### 1. Build the KMP Failure Function

```text
Pattern: A B A B A C
Index: 0 1 2 3 4 5
LPS: 0 0 1 2 3 0

LPS[i] = length of the longest proper prefix of pattern[0..i]
         that is also a suffix of pattern[0..i]

For pattern "ABABAC":
  i=0, A: no proper prefix/suffix → 0
  i=1, AB: "A" vs "B" → no match → 0
  i=2, ABA: "A" is both prefix and suffix → 1
  i=3, ABAB: "AB" is both → 2
  i=4, ABABA: "ABA" is both → 3
  i=5, ABABAC: no proper prefix == suffix → 0
```

### 2. Search Without Moving the Text Pointer Backward

For text `ABABABAC` and pattern `ABABAC`, the first five characters match. At text index 5, B disagrees with the expected C. Fall back from pattern position 5 to `LPS[4] = 3`: the already matched suffix ABA also matches the pattern prefix ABA. Compare the same text B with pattern position 3, then continue to find the occurrence starting at index 2. The text pointer does not rewind, and the retained prefix has a concrete reason to remain useful.

```text
Text: A B A B A B A C
Pattern: A B A B A C
         A B A B A match
At i=5, j=5: text[5]=B differs from pattern[5]=C.
Fall back to j=LPS[4]=3; text[5]=B matches pattern[3]=B.
Continue without moving i backward:
  i=6, j=4: A=A
  i=7, j=5: C=C → match starts at i-j=2
After the match, j=LPS[5]=0.
```

### 3. Filter Candidates With a Rolling Hash

```text
Text: A B A B A C A B A C ...
Pattern: A B A B A (length 5)
mod = large prime, base = 256

Initial hash:
  pattern[0..4] = 65·256^4 + 66·256^3 + 65·256^2 + 66·256 + 65
  text[0..4] = same calculation

For each shift i:
  hash(text[i+1..i+5]) = (hash(text[i..i+4]) - text[i]·base^4)·base + text[i+5]

This runs in O(1) per shift — total O(n) for the hash, plus O(m) per match for verification.
```

With many matches or collisions, the complete search can take O(nm). Grouping same-length patterns lets them share one text scan.

### 4. Run the Canonical Search Implementations

```typescript
// ==================== KMP ====================
function kmpSearch(text: string, pattern: string): number[] {
  if (pattern.length === 0) return [];
  const lps = computeLPS(pattern);
  const result: number[] = [];
  let i = 0; // index in text
  let j = 0; // index in pattern

  while (i < text.length) {
    if (text[i] === pattern[j]) {
      i++;
      j++;
      if (j === pattern.length) {
        result.push(i - j); // match found at index i - j
        j = lps[j - 1]; // continue searching
      }
    } else {
      if (j !== 0) {
        j = lps[j - 1]; // fallback using LPS, don't move i
      } else {
        i++;
      }
    }
  }

  return result;
}

function computeLPS(pattern: string): number[] {
  const lps = new Array(pattern.length).fill(0);
  let length = 0; // length of previous longest prefix-suffix
  let i = 1;

  while (i < pattern.length) {
    if (pattern[i] === pattern[length]) {
      length++;
      lps[i] = length;
      i++;
    } else {
      if (length !== 0) {
        length = lps[length - 1]; // try a shorter prefix
      } else {
        lps[i] = 0;
        i++;
      }
    }
  }

  return lps;
}

// ==================== Rabin-Karp ====================
function rabinKarpSearch(text: string, pattern: string): number[] {
  if (pattern.length === 0 || pattern.length > text.length) return [];
  const base = 256; // polynomial base; verification handles collisions
  const mod = 1_000_000_007; // large prime
  const m = pattern.length;

  // Compute initial hash of pattern and first window of text
  let patternHash = 0;
  let windowHash = 0;
  let h = 1; // base^(m-1) mod mod
  for (let i = 0; i < m - 1; i++) h = (h * base) % mod;

  for (let i = 0; i < m; i++) {
    patternHash = (patternHash * base + pattern.charCodeAt(i)) % mod;
    windowHash = (windowHash * base + text.charCodeAt(i)) % mod;
  }

  const result: number[] = [];
  for (let i = 0; i <= text.length - m; i++) {
    if (patternHash === windowHash) {
      // Verify character-by-character to avoid false positives
      let match = true;
      for (let k = 0; k < m; k++) {
        if (text[i + k] !== pattern[k]) { match = false; break; }
      }
      if (match) result.push(i);
    }
    // Roll the hash to the next window
    if (i < text.length - m) {
      const reduced = ((windowHash - text.charCodeAt(i) * h) % mod + mod) % mod;
      windowHash = (reduced * base + text.charCodeAt(i + m)) % mod;
      if (windowHash < 0) windowHash += mod; // handle negative
    }
  }

  return result;
}
```

### 5. Apply strStr, All-Occurrences, Multi-Pattern and Repetition Checks

```typescript
function strStr(haystack: string, needle: string): number {
  if (needle.length === 0) return 0;
  const lps = computeLPS(needle);
  let i = 0, j = 0;

  while (i < haystack.length) {
    if (haystack[i] === needle[j]) {
      i++;
      j++;
      if (j === needle.length) return i - j;
    } else {
      if (j !== 0) j = lps[j - 1];
      else i++;
    }
  }

  return -1;
}

console.log(strStr("sadbutsad", "sad")); // 0
console.log(strStr("leetcode", "leeto")); // -1
```

```typescript
function findAllOccurrences(text: string, pattern: string): number[] {
  return kmpSearch(text, pattern);
}

console.log(findAllOccurrences("abababab", "abab"));
// [0, 2, 4]
```

```typescript
function multiPatternSearch(text: string, patterns: string[]): Map<string, number[]> {
  const results = new Map<string, number[]>();
  const groups = new Map<number, Map<number, string[]>>();
  const base = 256, mod = 1_000_000_007;
  for (const pattern of new Set(patterns)) {
    results.set(pattern, []);
    if (pattern.length === 0 || pattern.length > text.length) continue;
    if (!groups.has(pattern.length)) groups.set(pattern.length, new Map());
    const buckets = groups.get(pattern.length)!;
    const hash = computeHash(pattern, base, mod);
    if (!buckets.has(hash)) buckets.set(hash, []);
    buckets.get(hash)!.push(pattern);
  }
  for (const [length, buckets] of groups) {
    let power = 1;
    for (let i = 1; i < length; i++) power = power * base % mod;
    let windowHash = computeHash(text.slice(0, length), base, mod);
    for (let start = 0; start <= text.length - length; start++) {
      for (const pattern of buckets.get(windowHash) ?? []) {
        if (text.startsWith(pattern, start)) results.get(pattern)!.push(start);
      }
      if (start < text.length - length) {
        const reduced = ((windowHash - text.charCodeAt(start) * power) % mod + mod) % mod;
        windowHash = (reduced * base + text.charCodeAt(start + length)) % mod;
      }
    }
  }
  return results;
}

function computeHash(s: string, base: number, mod: number): number {
  let hash = 0;
  // Index UTF-16 code units consistently with the rolling update.
  for (let i = 0; i < s.length; i++) hash = (hash * base + s.charCodeAt(i)) % mod;
  return hash;
}

const r = multiPatternSearch("the quick brown fox jumps", ["quick", "fox", "cat"]);
console.log(r.get("quick")); // [4]
console.log(r.get("fox")); // [16]
console.log(r.get("cat")); // []
```

```typescript
function repeatedSubstringPattern(s: string): boolean {
  // The string is a repetition of a substring iff
  // LPS[n-1] > 0 and n is divisible by (n - LPS[n-1])
  const n = s.length;
  if (n < 2) return false;
  const lps = computeLPS(s);
  const longest = lps[n - 1];
  return longest > 0 && n % (n - longest) === 0;
}

console.log(repeatedSubstringPattern("ababab")); // true
console.log(repeatedSubstringPattern("aba")); // false
console.log(repeatedSubstringPattern("abcabcabc")); // true
```

## Real-World Use Cases

Use **KMP** for "find all occurrences of pattern P in text T," shortest-prefix-that-is-a-suffix, pattern-cycle detection, and `strStr()`; use **Rabin-Karp** for "find all occurrences of any of K patterns in T," same-length substring fingerprint comparison, and plagiarism detection; use **naive search** for small inputs where its simpler implementation suffices and O(nm) is acceptable.

- **Foundation**: Implement strStr() (LeetCode 28) — basic KMP; Repeated Substring Pattern (LeetCode 459) — KMP LPS trick; String Matching in an Array (LeetCode 1408) — compare patterns with candidate words.
- **Advanced**: Longest Happy Prefix (LeetCode 1392) — KMP LPS; Shortest Palindrome (LeetCode 214) — KMP on the reverse; Longest Duplicate Substring (LeetCode 1044) — binary search with rolling hash.

## Common Mistakes

- **Confusing a proper prefix with the whole string.** A proper prefix is shorter; LPS[0] is zero. On mismatch, follow shorter prefix/suffix links until the current character can extend a valid border.
- **Skipping overlapping matches.** After a match, set j to its final LPS value instead of resetting blindly. The `abababab` example contains starts 0, 2 and 4.
- **Trusting equal hashes.** Verify actual characters. Many true matches also incur verification cost, even when there are no collisions.
- **Using JavaScript remainder as mathematical modulo.** Normalize the outgoing-character subtraction before multiplying. The shown constants keep intermediate integer arithmetic exact; larger mod/base choices need a new bound or BigInt.
- **Mixing character units.** These functions consistently index UTF-16 code units and report those offsets. Normalize Unicode only if the matching contract requires it; code points and graphemes need a consistent alternative representation.

## Performance Considerations

| Algorithm | Time (avg) | Time (worst) | Space |
| ------------------------------- | --------------------------------------- | ------------------------------ | ----------------------------- |
| Naive | O(nm) | O(nm) | O(1) |
| **KMP** | O(n+m) | O(n+m) | O(m) |
| **Rabin-Karp (single pattern)** | O(n+m) hash scan plus verification work | O(nm) | O(1) excluding output |
| **Rabin-Karp (K patterns)** | O(D·n + L) hash work plus verification | O(D·n + L + K·n·m) loose bound | O(K + D + m) excluding output |
| Z-algorithm | O(n+m) | O(n+m) | O(n+m) |

Here `D` is the number of distinct eligible lengths, `L` total pattern length, and `m` the maximum pattern length. All examples match UTF-16 code units and return code-unit offsets. Empty patterns produce no matches in the all-match helpers, while `strStr` deliberately follows the first-match API convention and returns 0. The reduced rolling update keeps Number arithmetic exact for the constants shown; changing constants requires rechecking intermediate bounds.

## Summary

KMP builds the LPS array in O(m) and scans with a forward-only text pointer, for O(n+m) total plus output storage. Rabin-Karp updates hashes in constant time but must verify every match, counting both true-match and collision verification in the runtime. Choose KMP for single-pattern deterministic linear time and Rabin-Karp for multi-pattern search, where equal-length patterns share one scan. The LPS array is reusable across strStr, repeated-substring and palindrome-prefix problems.

# Trie

Store both `app` and `apple`: they share the `app` path, but only a terminal marker says that `app` is a complete word. Prefix existence and exact-word lookup are different queries.

```typescript
const trie = new Trie();
trie.insert("apple"); trie.insert("app");
trie.search("apple");   // true — full word with terminal marker
trie.search("appl");    // false — path exists, no terminal marker
trie.startsWith("appl"); // true — prefix lookup only needs the path
```

## Definition

A **Trie** (prefix tree, digital tree) stores a dynamic set of strings as labeled edges consuming characters, where each node represents the prefix reached so far and the root represents the empty prefix. It is efficient for prefix-based operations like autocomplete, spell checking and word search.

> **Textbook Definition:** A trie stores keys as paths of shared prefixes, with terminal markers distinguishing complete keys from partial prefixes; lookup cost follows key length and the representation of child edges.

## First Principles

Tries exploit **shared prefixes** as the compression: storage and lookup scale with distinct prefixes, not total characters. A dictionary of words sharing stems pays once per prefix — the trade is pointer overhead versus a hash set's expected constant-time bucket lookup after hashing O(m) characters. Tries win when prefix queries (autocomplete, wildcard-by-prefix) are the actual product. A prefix is a partial answer: walking it locates the subtree containing completions, and enumerating that subtree is a separate step.

## Why It Matters

A trie makes prefix lookup direct: after reading a prefix, its subtree contains the possible completions. For exact matches alone, a hash set is usually simpler. A dictionary with total character count L creates at most L+1 trie nodes including the root; fixed-size child arrays can still consume much more memory than sparse maps. Radix trees compress single-child paths, double-array tries encode transitions in arrays, and minimal acyclic word automata merge equivalent suffix states — distinct representations, not interchangeable names.

## How It Works

### 1. Store Keys as Shared Prefix Paths

| Consumed prefix | What exists at that node |
| --------------- | --------------------------------------------- |
| app | A terminal marker for app; an outgoing l edge |
| appl | No terminal marker; outgoing e and i edges |
| apple | A terminal marker for apple |
| application | A terminal marker for application |

Searching `appl` reaches a node but fails the terminal check; prefix lookup for `appl` succeeds. Exact lookup consumes the whole word and checks the terminal marker — prefix lookup only requires the path. Autocomplete then enumerates the subtree; returning many completions costs time proportional to that output.

### 2. Carry the Node-and-Trie Template

JavaScript `for...of` consumes Unicode code points here, not grapheme clusters. Normalize text consistently if canonically equivalent spellings should match. The basic trie permits the empty key: inserting it marks the root, and the empty prefix exists even in an otherwise empty trie.

```typescript
class TrieNode {
  children: Map<string, TrieNode>;
  isEnd: boolean;

  constructor() {
    this.children = new Map();
    this.isEnd = false;
  }
}

class Trie {
  readonly root: TrieNode;

  constructor() {
    this.root = new TrieNode();
  }

  insert(word: string): void {
    let node = this.root;
    for (const char of word) {
      if (!node.children.has(char)) {
        node.children.set(char, new TrieNode());
      }
      node = node.children.get(char)!;
    }
    node.isEnd = true;
  }

  search(word: string): boolean {
    let node = this.root;
    for (const char of word) {
      if (!node.children.has(char)) return false;
      node = node.children.get(char)!;
    }
    return node.isEnd;
  }

  startsWith(prefix: string): boolean {
    let node = this.root;
    for (const char of prefix) {
      if (!node.children.has(char)) return false;
      node = node.children.get(char)!;
    }
    return true;
  }
}
```

```typescript
// Reuse Trie and TrieNode from the template above.

// Example
const trie = new Trie();
trie.insert("apple");
trie.insert("app");
trie.insert("application");
console.log(trie.search("apple")); // true
console.log(trie.search("app")); // true
console.log(trie.startsWith("app")); // true
console.log(trie.startsWith("apl")); // false
```

### 3. Insert Words and Search With Wildcards

```typescript
class WordDictionary {
  private root: TrieNode;

  constructor() {
    this.root = new TrieNode();
  }

  addWord(word: string): void {
    let node = this.root;
    for (const char of word) {
      if (!node.children.has(char)) {
        node.children.set(char, new TrieNode());
      }
      node = node.children.get(char)!;
    }
    node.isEnd = true;
  }

  search(word: string): boolean {
    return this.dfs(Array.from(word), 0, this.root);
  }

  private dfs(word: string[], index: number, node: TrieNode): boolean {
    if (index === word.length) return node.isEnd;

    const char = word[index];

    if (char === '.') {
      for (const child of node.children.values()) {
        if (this.dfs(word, index + 1, child)) return true;
      }
      return false;
    }

    if (!node.children.has(char)) return false;

    return this.dfs(word, index + 1, node.children.get(char)!);
  }
}

// Example
const wordDict = new WordDictionary();
wordDict.addWord("bad");
wordDict.addWord("dad");
wordDict.addWord("mad");
console.log(wordDict.search("pad")); // false
console.log(wordDict.search("bad")); // true
console.log(wordDict.search(".ad")); // true
console.log(wordDict.search("b..")); // true
```

### 4. Traverse Boards and Dictionaries With Trie Pruning

Contract: a rectangular board of single lowercase English letters and nonempty lowercase words. `#` is reserved as a temporary visited marker. One cell cannot be reused within a word; restoring its letter permits other paths to use it later. The helper builds its own trie and clears terminal markers after a discovery to emit each word once.

```typescript
function findWords(board: string[][], words: string[]): string[] {
  if (board.length === 0 || board[0].length === 0) return [];
  const result: string[] = [];

  // Build trie from words
  const trie = new Trie();
  for (const word of words) {
    trie.insert(word);
  }

  const rows = board.length;
  const cols = board[0].length;

  function dfs(r: number, c: number, node: TrieNode, word: string): void {
    if (node.isEnd) {
      result.push(word);
      node.isEnd = false; // avoid duplicates
    }

    if (r < 0 || r >= rows || c < 0 || c >= cols) return;

    const char = board[r][c];
    if (char === '#' || !node.children.has(char)) return;

    board[r][c] = '#'; // mark visited

    const childNode = node.children.get(char)!;
    dfs(r + 1, c, childNode, word + char);
    dfs(r - 1, c, childNode, word + char);
    dfs(r, c + 1, childNode, word + char);
    dfs(r, c - 1, childNode, word + char);

    board[r][c] = char; // restore
  }

  for (let r = 0; r < rows; r++) {
    for (let c = 0; c < cols; c++) {
      if (trie.root.children.has(board[r][c])) {
        dfs(r, c, trie.root, '');
      }
    }
  }

  return result;
}

// Example
const board = [
  ["o","a","a","n"],
  ["e","t","a","e"],
  ["i","h","k","r"],
  ["i","f","l","v"]
];
const words = ["oath","pea","eat","rain"];
console.log(findWords(board, words)); // ["oath","eat"] (the result set matters; traversal order is not part of the contract)
```

This task requires every nonempty prefix to be stored, and breaks equal-length ties lexicographically. The example assumes lowercase English words, matching its interview contract.

```typescript
function longestWord(words: string[]): string {
  const trie = new Trie();
  for (const word of words) {
    trie.insert(word);
  }

  let longest = '';

  function dfs(node: TrieNode, current: string): void {
    if (current.length > longest.length || (current.length === longest.length && current < longest)) {
      longest = current;
    }

    for (const [char, childNode] of node.children) {
      if (childNode.isEnd) {
        dfs(childNode, current + char);
      }
    }
  }

  dfs(trie.root, '');
  return longest;
}

// Example
console.log(longestWord(["w","wo","wor","worl","world"])); // "world"
console.log(longestWord(["a","ap","app","appl","apple"])); // "apple"
```

### 5. Replace by Shortest Root and Sum by Prefix

Use nonempty lowercase roots and a sentence separated by literal spaces. Stop at the first terminal marker so the shortest stored root wins. This tokenizer is an interview contract, not a complete natural-language word boundary implementation.

```typescript
function replaceWords(dictionary: string[], sentence: string): string {
  const trie = new TrieNode();

  // Build trie
  for (const root of dictionary) {
    let node = trie;
    for (const char of root) {
      if (!node.children.has(char)) {
        node.children.set(char, new TrieNode());
      }
      node = node.children.get(char)!;
    }
    node.isEnd = true;
  }

  // Find shortest root for each word
  function findRoot(word: string): string {
    let node = trie;
    let prefix = '';
    for (const char of word) {
      if (node.isEnd) return prefix;
      if (!node.children.has(char)) return word; // no stored root: keep original
      node = node.children.get(char)!;
      prefix += char;
    }
    return node.isEnd ? prefix : word;
  }

  return sentence.split(' ').map(findRoot).join(' ');
}

// Example
console.log(replaceWords(
  ["cat", "bat", "rat"],
  "the cattle was rattled by the battery"
)); // "the cat was rat by the bat"
```

Reinserting apple with 5 after 3 adds only the difference 2 along its prefix path. Adding 5 again would double-count the old value. This example assumes finite values and sums within JavaScript Number precision; the empty-prefix query reads the root total.

```typescript
class SumTrieNode {
  children: Map<string, SumTrieNode>;
  value: number;

  constructor() {
    this.children = new Map();
    this.value = 0;
  }
}

class MapSum {
  private root: SumTrieNode;
  private map: Map<string, number>;

  constructor() {
    this.root = new SumTrieNode();
    this.map = new Map();
  }

  insert(key: string, val: number): void {
    const delta = val - (this.map.get(key) || 0);
    this.map.set(key, val);

    let node = this.root;
    node.value += delta; // empty-prefix sum includes every key
    for (const char of key) {
      if (!node.children.has(char)) {
        node.children.set(char, new SumTrieNode());
      }
      node = node.children.get(char)!;
      node.value += delta;
    }
  }

  sum(prefix: string): number {
    let node = this.root;
    for (const char of prefix) {
      if (!node.children.has(char)) return 0;
      node = node.children.get(char)!;
    }
    return node.value;
  }
}

// Example
const mapSum = new MapSum();
mapSum.insert("apple", 3);
console.log(mapSum.sum("ap")); // 3
mapSum.insert("app", 2);
console.log(mapSum.sum("ap")); // 5
```

## Real-World Use Cases

Reach for tries for prefix-based searches, autocomplete and autosuggest features, lexicon-based word games or spell-check candidate search combined with edit-distance logic, word games (Boggle, Word Search II), IP routing, and any prefix-matching problem.

- **Start with the state**: Implement Trie (Prefix Tree) (LeetCode 208, Medium); Longest Common Prefix (LeetCode 14).
- **Combine the mechanisms**: Design Add and Search Words Data Structure (LeetCode 211); Word Search II (LeetCode 212, Hard); Longest Word in Dictionary (LeetCode 720); Map Sum Pairs (LeetCode 677); Replace Words (LeetCode 648); Search Suggestions System (LeetCode 1268).
- **Extend the reasoning**: Palindrome Pairs (LeetCode 336); Stream of Characters (LeetCode 1032); Concatenated Words (LeetCode 472) — trie search with word-break reasoning.

## Common Mistakes

1. **Not handling edge cases**: Empty strings, single characters

2. **Forgetting to mark end of word**: Always set `isEnd = true` after inserting

3. **Not cleaning up after removal**: If implementing deletion, handle all cases

4. **Ignoring the alphabet and memory tradeoff**: Sparse maps support varied keys; fixed child arrays can be efficient for a small known alphabet but reserve unused slots.

5. **Not checking for null**: Always verify node exists before accessing children

## Performance Considerations

| Operation | Time | Space |
| ---------- | ---- | ----- |
| Insert | O(m) | O(m) |
| Search | O(m) | O(1) |
| StartsWith | O(m) | O(1) |

- **m**: number of code points for these Map-based helpers; their access bounds assume expected constant-time map operations.
- A dot in WordDictionary matches one code point. Wildcard queries can explore many branches rather than one O(m) path; the recursive search also stores the converted query and call stack.
- Board search can explore exponentially many paths in the maximum word length, though missing trie prefixes prune work; its recursion and temporary strings add workspace.
- **Space**: O(N × m) total for N words, but often less due to shared prefixes

## Summary

A trie stores one path per distinct prefix and a terminal marker for complete words. Exact lookup and prefix existence require different checks. Prefix enumeration, wildcard branching, and board traversal add their own costs; trie lookup alone does not make them constant-time.

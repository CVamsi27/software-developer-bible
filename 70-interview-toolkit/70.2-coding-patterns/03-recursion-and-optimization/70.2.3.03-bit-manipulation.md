# Bit Manipulation

Suppose every value in an array appears twice except one. XOR can recover that value in one pass and constant space — but only when the integer-width and multiplicity assumptions hold.

```typescript
singleNumber([4, 1, 2, 1, 2]); // 4 — paired values cancel
```

## Definition

**Bit manipulation** uses masks, shifts and boolean operations on an integer's binary representation. A fixed-width word can encode a small set, flags or a compact state. The arithmetic model matters: JavaScript Number bitwise operations coerce to 32 bits, while Number arithmetic itself is floating-point. BigInt supports wider integer bitwise operations with costs growing in operand size.

> **Textbook Definition:** Bit manipulation operates on an integer's binary representation through masks, shifts and Boolean operations, with correctness determined by the language's width, signedness and coercion rules.

## First Principles

Bit tricks exploit **representation parallelism**: a fixed-width word stores several boolean positions, so sets as bitmasks make union and intersection single instructions. The win is constant factors and memory, not complexity class. **XOR's algebra** (self-inverse, associative) does the heavy lifting: paired elements cancel and the unpaired value survives. At each position, XOR adds modulo two — equal bits cancel. The cancellation depends on input multiplicities; three copies do not disappear.

## How It Works

### 1. Cancel Pairs With XOR Algebra

```text
XOR (^) returns 1 if bits differ, 0 if same

a ^ a = 0 (a number XOR itself is 0)
a ^ 0 = a (a number XOR 0 is itself)
a ^ b = b ^ a (commutative)
a ^ (b ^ c) = (a ^ b) ^ c (associative)

APPLICATION: "Find the unique number" in [2, 3, 5, 3, 2]
  0 ^ 2 = 2
  2 ^ 3 = 1
  1 ^ 5 = 4
  4 ^ 3 = 7
  7 ^ 2 = 5 ← unique!
```

### 2. Clear the Lowest Set Bit and Mask Sets

```text
n = 12 = 1100

n & (n-1):
  1100 & 1011 = 1000 (lowest set bit cleared)
  1000 & 0111 = 0000 (lowest set bit cleared)

Each iteration removes the lowest set bit → runs in O(popcount) time.
For 32-bit ints: at most 32 iterations.
```

```text
Set {a, c} of {a, b, c, d} → bitmask 0101
  bit 0 (a) = 1
  bit 1 (b) = 0
  bit 2 (c) = 1
  bit 3 (d) = 0

Union: 0101 | 0011 = 0111
Intersect: 0101 & 0011 = 0001
Difference: 0101 & ~0011 = 0100
Toggle: 0101 ^ 0010 = 0111
```

### 3. Carry the Bit Building Blocks

The mask helpers use integer inputs representing 32-bit patterns and return unsigned values. The XOR-selection helpers interpret results as signed 32-bit integers and require the stated multiplicities. `>>> 0` changes interpretation of the same pattern; it does not recover bits discarded by coercion.

```typescript
// ==================== Bit Building Blocks ====================

function checkBitPosition(i: number): void {
  if (!Number.isInteger(i) || i < 0 || i > 31) throw new RangeError("bit position 0..31 required");
}

// Check if bit i is set
function isSet(num: number, i: number): boolean {
  checkBitPosition(i);
  return (num & (1 << i)) !== 0;
}

// Set bit i
function setBit(num: number, i: number): number {
  checkBitPosition(i);
  return (num | (1 << i)) >>> 0;
}

// Clear bit i
function clearBit(num: number, i: number): number {
  checkBitPosition(i);
  return (num & ~(1 << i)) >>> 0;
}

// Toggle bit i
function toggleBit(num: number, i: number): number {
  checkBitPosition(i);
  return (num ^ (1 << i)) >>> 0;
}

// Count set bits — Brian Kernighan's algorithm
function popcount(n: number): number {
  n >>>= 0; // interpret the input as a 32-bit pattern
  let count = 0;
  while (n !== 0) {
    n &= n - 1; // remove lowest set bit
    count++;
  }
  return count;
}

// Check if n is a power of 2
function isPowerOfTwo(n: number): boolean {
  return Number.isInteger(n) && n > 0 && n <= 0xffffffff && (n & (n - 1)) === 0;
}

// ==================== Common Patterns ====================

// Find the unique number (others appear twice) — XOR
function findUnique(nums: number[]): number {
  return nums.reduce((acc, n) => acc ^ n, 0);
}

// Find two unique numbers (others appear twice)
function findTwoUniques(nums: number[]): [number, number] {
  let xor = 0;
  for (const n of nums) xor ^= n; // XOR of all = a ^ b (a, b are uniques)
  const rightmostSetBit = xor & -xor; // isolate lowest set bit
  let a = 0, b = 0;
  for (const n of nums) {
    if ((n & rightmostSetBit) === 0) a ^= n; // group 1
    else b ^= n; // group 2
  }
  return [a, b];
}

// Generate all subsets via bitmask
function subsets<T>(nums: T[]): T[][] {
  const result: T[][] = [];
  const n = nums.length;
  if (n > 30) throw new RangeError("this 32-bit enumeration supports at most 30 elements");
  for (let mask = 0; mask < 2 ** n; mask++) {
    const subset: T[] = [];
    for (let i = 0; i < n; i++) {
      if ((mask & (1 << i)) !== 0) subset.push(nums[i]);
    }
    result.push(subset);
  }
  return result;
}
```

### 4. Solve Single-Number, Popcount, Subset and Reverse-Bits Cases

```typescript
function singleNumber(nums: number[]): number {
  return findUnique(nums); // reuse the cancellation mechanism
}

console.log(singleNumber([4, 1, 2, 1, 2])); // 4
```

```typescript
function hammingWeight(n: number): number {
  return popcount(n); // shared 32-bit implementation above
}

console.log(hammingWeight(0b1011)); // 3 (binary 1011 has three 1s)
```

```typescript
// Reuse the generic subsets implementation above.

console.log(subsets([1, 2, 3]));
// [[], [1], [2], [1,2], [3], [1,3], [2,3], [1,2,3]]
```

```typescript
function reverseBits(n: number): number {
  let result = 0;
  for (let i = 0; i < 32; i++) {
    result = (result << 1) | (n & 1); // shift result left, add current LSB
    n >>>= 1; // unsigned right shift
  }
  return result >>> 0; // force unsigned 32-bit
}

console.log(reverseBits(0b00000010100101000001111010011100));
// 964176192 (binary: 00111001011110000010100101000000)
```

### 5. Check Powers of Two, Find Missing Numbers and Gate Permissions

A positive power of two has one set bit. Subtracting one clears that bit and sets every lower bit, so AND gives zero. The shared `isPowerOfTwo` above rejects zero, fractions and values outside the unsigned 32-bit range.

```typescript
console.log(isPowerOfTwo(8)); // true
console.log(isPowerOfTwo(0)); // false
```

Contract: distinct values from 0..n, with exactly one missing and n within signed 32-bit range. XOR each expected index and present value; pairs cancel and leave the missing value. Duplicate or out-of-range inputs violate that proof.

```typescript
function missingNumber(nums: number[]): number {
  // XOR of [0..n] XOR XOR of nums = missing number
  // (because all values present in both cancel out)
  const n = nums.length;
  let xor = n;
  for (let i = 0; i < n; i++) {
    xor ^= i ^ nums[i];
  }
  return xor;
}

console.log(missingNumber([3, 0, 1])); // 2
console.log(missingNumber([0, 1, 2, 3, 4, 5, 6, 7, 9])); // 8
```

Each flag represents an independent permission; ADMIN does not automatically imply the other flags. Testing a combined mask requires all its bits, while `hasAny` accepts one. `hasAll(0)` is true because the empty requirement needs nothing. These methods only manipulate a local representation: authorize against server-owned identity and policy before granting access.

```typescript
// Permissions as bit flags
const Permission = {
  READ: 1 << 0, // 0b0001
  WRITE: 1 << 1, // 0b0010
  DELETE: 1 << 2, // 0b0100
  ADMIN: 1 << 3, // 0b1000
} as const;

class User {
  private perms: number = 0;

  grant(perm: number): void { this.perms |= perm; }
  revoke(perm: number): void { this.perms &= ~perm; }
  has(perm: number): boolean { return (this.perms & perm) === perm; }
  hasAny(perms: number): boolean { return (this.perms & perms) !== 0; }
  hasAll(perms: number): boolean { return (this.perms & perms) === perms; }
}

const alice = new User();
alice.grant(Permission.READ | Permission.WRITE);

console.log(alice.has(Permission.READ)); // true
console.log(alice.has(Permission.DELETE)); // false
console.log(alice.hasAll(Permission.READ | Permission.WRITE)); // true
```

## Real-World Use Cases

Reach for bit tricks for "find the unique element" (XOR cancels duplicates), "count set bits" via `n & (n - 1)` in O(popcount), power-of-2 checks with `n > 0 && (n & (n - 1)) === 0`, subset generation by iterating masks, permission flags and set operations as integers, and bit-shift reversal. Look for small sets or compact states encodable as flags, or tasks asking which bits differ or are missing.

- **Establish the state**: Single Number (LeetCode 136) — XOR of duplicates cancels; Number of 1 Bits (LeetCode 191) — Brian Kernighan; Reverse Bits (LeetCode 190) — shift and mask; Power of Two (LeetCode 231) — one set bit; Missing Number (LeetCode 268) — XOR or sum formula; Hamming Distance (LeetCode 461) — XOR then popcount; Sum of Two Integers (LeetCode 371, Medium) — full adder in bitwise.
- **Combine choices and states**: Single Number II (LeetCode 137) — every other appears 3 times; Single Number III (LeetCode 260) — two unique numbers; Subsets (LeetCode 78) — bitmask enumeration; Bitwise AND of Numbers Range (LeetCode 201) — find common prefix; Maximum Product of Word Lengths (LeetCode 318) — bitmask for character sets; Counting Bits (LeetCode 338, Easy) — DP + bit trick; Find the Difference (LeetCode 389, Easy) — XOR trick; UTF-8 Validation (LeetCode 393) — bit-level parsing.
- **Extend the constraints**: Minimum Number of K Consecutive Bit Flips (LeetCode 995) — sliding window + bit flip; Maximum XOR With an Element From Array (LeetCode 1707) — bit trie; Find K-th Smallest Pair Distance (LeetCode 719) — related binary search plus pair counting; Shortest Path to Get All Keys (LeetCode 864) — bitmask BFS; Maximum Score Words Formed by Letters (LeetCode 1255) — bitmask DP.

## Common Mistakes

- **Changing signedness accidentally:** `-1 >> 1` stays −1, while `-1 >>> 1` becomes 2147483647. Choose the contract before shifting. BigInt has signed right shift but no `>>>`.
- **Relying on precedence:** write `(n & 1) === 1`. Without parentheses, equality binds first; strict TypeScript also rejects AND with the Boolean comparison result.
- **Shifting beyond the word:** `1 << 32` is 1 because Number shift counts use their low five bits. Exact Number arithmetic can represent wider integers, but these bitwise operators still use 32 bits.
- **Confusing cancellation with validation:** XOR cannot verify that all other values occur twice. Establish that input promise separately.
- **Ignoring output growth:** the subset helper's 30-element limit is a width bound, not a practical memory budget. Returning 2^n copied subsets requires a much smaller n in typical programs.

## Performance Considerations

| Operation | Time | Space |
| -------------------------------- | ------------------- | ---------- |
| Bit count (Brian Kernighan) | O(popcount) ≤ O(32) | O(1) |
| Check / set / clear / toggle bit | O(1) | O(1) |
| Find unique (XOR) | O(n) | O(1) |
| Generate all subsets (bitmask) | O(n × 2^n) | O(n × 2^n) |
| Reverse bits | O(32) | O(1) |
| Permission system | O(1) per op | O(1) |

## Summary

Bit manipulation operates on integers as binary vectors: `&` masks, `|` sets, `^` toggles, `~` negates, and shifts reposition bits. XOR's self-inverse and associative algebra cancels paired values, while `n & (n - 1)` removes the lowest set bit for O(popcount) counting. A 32-bit word holds a 32-element set with O(1) union, intersection and toggle. The senior signals are choosing bitmasks for permission systems, XOR for find-the-unique, and recognizing bit-counting opportunities — while watching signedness, precedence and JavaScript's 32-bit coercion boundary.

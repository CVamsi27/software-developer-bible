# Mock Interview Bank — 20 Curated Questions for EU Mid-Stage

> **20 questions curated for EU mid-stage full-stack loops.** Mix of behavioral, technical, and system design. Practice with a friend or on Pramp/interviewing.io.

## TL;DR

- **20 questions:** 8 behavioral + 7 technical + 5 system design
- **Each question has:** the question itself, what they're testing, a 60-second answer skeleton
- **Practice 2-3 per mock interview.** A 90-min mock covers 1 behavioral + 1 technical + 1 system design.
- **For full stories:** see [story-bank.md](80.12-story-bank.md). For full case frameworks: see [System Design Case Bank](80.08-system-design-case-bank.md).

## 7 Technical Questions

### Q9: "Implement a rate limiter" (30 min)

**What they test:** Can you code a focused system with multiple valid approaches?

**Approach:**
1. Clarify: per-user? per-IP? per-API-key? window type (fixed, sliding)?
2. Discuss: in-memory (Redis) vs in-process
3. Implement: token bucket or sliding window counter
4. Discuss: edge cases (clock skew, concurrent requests, TTL)

**Skeleton:**
```typescript
class RateLimiter {
  private buckets = new Map<string, TokenBucket>();

  constructor(
    private capacity: number,
    private refillRate: number  // tokens per second
  ) {}

  allow(key: string): boolean {
    const now = Date.now();
    let bucket = this.buckets.get(key);
    if (!bucket) {
      bucket = { tokens: this.capacity, lastRefill: now };
      this.buckets.set(key, bucket);
    }
    // Refill
    const elapsed = (now - bucket.lastRefill) / 1000;
    bucket.tokens = Math.min(this.capacity, bucket.tokens + elapsed * this.refillRate);
    bucket.lastRefill = now;
    // Consume
    if (bucket.tokens >= 1) {
      bucket.tokens -= 1;
      return true;
    }
    return false;
  }
}
```

**Follow-ups:** "How would you scale this across multiple servers?" (Redis with Lua), "How would you handle clock skew?" (use Redis TTL), "How would you rate-limit by IP?" (use IP as key, handle IPv6).

### Q12: "Implement a function to merge k sorted lists" (30 min)

**What they test:** Heap, divide and conquer

**Approach:**
1. Clarify: k value, list sizes
2. Discuss: min-heap (priority queue) vs divide-and-conquer
3. Implement: min-heap approach (O(N log k))
4. Discuss: complexity, alternative approaches

```typescript
function mergeKLists(lists: ListNode[]): ListNode {
  const heap: [number, ListNode][] = [];
  for (const list of lists) {
    if (list) heap.push([list.val, list]);
  }
  heap.sort((a, b) => a[0] - b[0]);  // simplified, use real heap in prod

  const dummy = new ListNode(0);
  let tail = dummy;
  while (heap.length > 0) {
    const [val, node] = heap.shift()!;
    tail.next = node;
    tail = tail.next;
    if (node.next) {
      heap.push([node.next.val, node.next]);
      heap.sort((a, b) => a[0] - b[0]);
    }
  }
  return dummy.next;
}
```

### Q13: "Find the longest substring without repeating characters" (20 min)

**What they test:** Sliding window + HashMap

**Approach:**
1. Clarify: empty string? single char? case-sensitive?
2. Implement: sliding window with HashMap of char → last index

```typescript
function lengthOfLongestSubstring(s: string): number {
  const seen = new Map<string, number>();
  let max = 0, start = 0;
  for (let i = 0; i < s.length; i++) {
    const c = s[i];
    if (seen.has(c) && seen.get(c)! >= start) {
      start = seen.get(c)! + 1;
    }
    seen.set(c, i);
    max = Math.max(max, i - start + 1);
  }
  return max;
}
```

### Q14: "Implement debounce and throttle" (20 min)

**What they test:** Closures, setTimeout, async patterns

**Approach:**
1. Clarify: leading vs trailing edge, immediate vs delayed
2. Implement: both with options

```typescript
function debounce<T extends (...args: any[]) => any>(
  fn: T, wait: number
): T & { cancel: () => void } {
  let timer: NodeJS.Timeout | null = null;
  const debounced = ((...args: any[]) => {
    if (timer) clearTimeout(timer);
    timer = setTimeout(() => fn(...args), wait);
  }) as T & { cancel: () => void };
  debounced.cancel = () => {
    if (timer) clearTimeout(timer);
  };
  return debounced;
}
```

### Q15: "Detect a cycle in a linked list" (15 min)

**What they test:** Two pointers, fast/slow

**Approach:**
- Floyd's cycle detection: slow + fast pointers
- If they meet, there's a cycle

```typescript
function hasCycle(head: ListNode | null): boolean {
  let slow = head, fast = head;
  while (fast?.next) {
    slow = slow!.next;
    fast = fast.next.next;
    if (slow === fast) return true;
  }
  return false;
}
```

## Mock interview structure (90 min)

| Time | What | Why |
|------|------|-----|
| 0-5 min | Intro, interviewer sets the stage | Warm up |
| 5-25 min | 1 behavioral question (pick from Q1-Q8) | Test STAR+R delivery |
| 25-55 min | 1 technical question (pick from Q9-Q15) | Test coding under pressure |
| 55-90 min | 1 system design question (pick from Q16-Q20) | Test 4-phase framework |
| 90-95 min | 5 min for your questions to the interviewer | Test curiosity |

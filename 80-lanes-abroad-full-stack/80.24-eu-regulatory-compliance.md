# EU Regulatory Compliance — GDPR, BaFin, EU AI Act, Digital Services Act

> Every German product company must comply with EU regulations. This guide covers what you need to know for interviews.

---

## GDPR (General Data Protection Regulation)

### Core Principles
| Principle                       | What It Means                       | Engineering Impact                               |
| -----------                       | ---------------                       | -------------------                                |
| **Lawfulness**                  | Need legal basis for processing     | Consent forms, legitimate interest documentation |
| **Purpose limitation**          | Collect only for stated purpose     | Data flow diagrams, purpose tags on fields       |
| **Data minimization**           | Collect only what's needed          | Audit all fields, remove unnecessary data        |
| **Accuracy**                    | Keep data correct and updated       | Edit endpoints, soft deletes                     |
| **Storage limitation**          | Don't keep longer than needed       | TTL on data, automated deletion                  |
| **Integrity & confidentiality** | Protect against unauthorized access | Encryption at rest/transit, RBAC, audit logs     |
| **Accountability**              | Demonstrate compliance              | Documentation, DPIA, records of processing       |

### Data Protection Impact Assessment (DPIA)
```markdown
## DPIA Template

### 1. Description of Processing
- What data: Patient records, appointments, prescriptions
- Purpose: Healthcare clinic management
- Data subjects: Patients, clinicians, clinic staff
- Volume: 25 clinics × 1000 patients = 25,000 data subjects

### 2. Legal Basis
- Consent: Patients consent to data processing for healthcare
- Contract: Clinic processes data to provide healthcare services
- Legal obligation: Medical records retention

### 3. Risk Assessment
| Risk | Likelihood | Impact | Mitigation |
|------|------------|--------|------------|
| Unauthorized access | Medium | High | RBAC + ABAC + RLS |
| Data breach | Low | High | Encryption + audit logs |
| Cross-tenant leakage | Low | High | RLS + cross-clinic tests |
| Data loss | Low | Medium | Daily backups + WAL archiving |

### 4. Technical Measures
- Encryption at rest and in transit
- Row-level security
- Audit logging
- Access controls (RBAC + ABAC)
- Data masking in logs

### 5. Organizational Measures
- Staff training on data protection
- Incident response procedure
- Data processor agreements (DPA)
- Regular security audits
```

## BaFin (German Financial Authority)

### Requirements for Fintech Companies
| Requirement                               | What It Means                  | Engineering Impact                               |
| -------------                               | ---------------                  | -------------------                                |
| **KYC (Know Your Customer)**              | Verify customer identity       | ID verification, document upload, liveness check |
| **AML (Anti-Money Laundering)**           | Detect suspicious transactions | Transaction monitoring, SAR reporting            |
| **PSD2 (Payment Services)**               | Open banking, SCA              | OAuth 2.0, 3D Secure, consent management         |
| **MaS (Minimum Security)**                | Technical security standards   | Encryption, access controls, incident response   |
| **DORA (Digital Operational Resilience)** | ICT risk management            | Business continuity, disaster recovery, testing  |

### Engineering Implications
```typescript
// BaFin compliance checklist for engineers
const bafinChecklist = {
  // KYC
  kyc: {
    identityVerification: 'Integration with ID verification provider',
    documentUpload: 'Encrypted storage, retention policy',
    livenessCheck: 'Anti-spoofing biometric verification'
  },

  // AML
  aml: {
    transactionMonitoring: 'Rule engine + ML for suspicious patterns',
    suspiciousActivityReports: 'Automated SAR generation',
    recordKeeping: '7-year retention of all transactions'
  },

  // PSD2
  psd2: {
    strongCustomerAuthentication: '3D Secure 2.0 or biometric',
    openBanking: 'OAuth 2.0 with AISP/PISP roles',
    consentManagement: 'Granular consent, easy withdrawal'
  },

  // Incident Response
  incidentResponse: {
    notification: 'BaFin must be notified within 24 hours',
    documentation: 'Full incident report within 1 month',
    testing: 'Annual penetration testing'
  }
};
```

## EU AI Act (2024)

### Risk Categories
| Risk Level       | Examples                          | Requirements                                   |
| ------------       | ----------                          | --------------                                   |
| **Unacceptable** | Social scoring, manipulation      | Banned                                         |
| **High**         | Medical diagnosis, credit scoring | Risk assessment, human oversight, transparency |
| **Limited**      | Chatbots, emotion recognition     | Transparency obligations                       |
| **Minimal**      | Spam filters, games               | No specific requirements                       |

### Healthcare AI Implications

## Digital Services Act (DSA)

### Requirements for Platform Companies
| Requirement                  | What It Means                     | Engineering Impact                         |
| -------------                  | ---------------                     | -------------------                          |
| **Content moderation**       | Remove illegal content            | Automated detection, human review, appeals |
| **Transparency**             | Report content moderation actions | Public reports, API for researchers        |
| **User notification**        | Inform users of content removal   | Real-time notifications, appeal process    |
| **Algorithmic transparency** | Explain recommendation algorithms | Documentation, opt-out options             |

### Engineering Implications
```typescript
// DSA compliance for platform companies
const dsaChecklist = {
```

## Digital Operational Resilience Act (DORA)

### Requirements for Financial Companies
| Requirement                                | What It Means                               | Engineering Impact                                 |
| -------------                                | ---------------                               | -------------------                                  |
| **ICT risk management**                    | Identify, protect, detect, respond, recover | Security monitoring, incident response             |
| **Incident reporting**                     | Report major ICT incidents to regulator     | Automated incident detection, reporting pipeline   |
| **Digital operational resilience testing** | Regular penetration testing, TLPT           | Annual pen testing, threat-led penetration testing |
| **Third-party risk**                       | Manage vendor ICT risk                      | Vendor assessment, SLA monitoring                  |
| **Information sharing**                    | Share threat intelligence                   | ISAC participation, threat feeds                   |

## Interview Questions

### GDPR Questions
| Question                                         | Answer                                                                                                   |
| ----------                                         | --------                                                                                                   |
| "How do you implement GDPR data subject rights?" | "Export endpoint generates JSON/CSV bundle, soft-delete with tombstone, audit trail retained separately" |
| "How do you handle cross-border data transfers?" | "Data stays in EU region, Schrems II compliance, SCCs for US vendors"                                    |
| "How do you ensure data minimization?"           | "Audit all fields quarterly, remove unused fields, anonymize analytics data"                             |
| "How do you handle data breach notification?"    | "72-hour notification to supervisory authority, document all steps, notify affected individuals"         |

### BaFin Questions
| Question                                     | Answer                                                                           |
| ----------                                     | --------                                                                           |
| "How do you implement KYC?"                  | "ID verification provider + document upload + liveness check, encrypted storage" |
| "How do you detect suspicious transactions?" | "Rule engine + ML scoring, automated SAR generation, manual review queue"        |
| "How do you implement PSD2 SCA?"             | "3D Secure 2.0 with biometric fallback, risk-based authentication"               |

### EU AI Act Questions
| Question                                           | Answer                                                                                         |
| ----------                                           | --------                                                                                         |
| "How do you classify AI risk in healthcare?"       | "High-risk: diagnosis, treatment, risk scoring. Limited-risk: chatbots. Minimal: spam filters" |
| "What documentation do you need for high-risk AI?" | "Risk management system, training data docs, technical docs, logging, human oversight"         |
| "How do you ensure AI transparency?"               | "Inform users of AI involvement, explain decision factors, provide opt-out"                    |

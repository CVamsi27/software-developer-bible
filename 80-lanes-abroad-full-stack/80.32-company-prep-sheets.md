## 1. Redcare Pharmacy (redcare.de)

### Company Profile

| Attribute | Details |
|-----------|---------|
| **Industry** | Online pharmacy / Healthtech |
| **Size** | 1,000+ employees |
| **Funding** | Public (Frankfurt Stock Exchange) |
| **HQ** | Amsterdam, Germany operations in Berlin |
| **Stack** | Java/Spring Boot, React, PostgreSQL, Kafka, Kubernetes |
| **Culture** | Engineering-driven, data-informed, fast-paced |

### What They Care About

1. **Scalability** — They handle millions of orders; your system design must show scale
2. **Reliability** — Medication delivery is critical; uptime matters
3. **Data-driven** — They A/B test everything; mention metrics and experimentation
4. **Healthcare compliance** — GDPR, pharmacy regulations

### Likely Interview Questions

| Question | What They're Testing |
|----------|---------------------|
| "Design a medication recommendation engine" | ML integration, data pipeline |
| "How do you handle peak traffic during flu season?" | Auto-scaling, caching, CDN |
| "How do you ensure medication data accuracy?" | Data validation, audit logging |
| "Design the order fulfillment pipeline" | Event-driven architecture, Saga pattern |

### Your Talking Points

- **Docita connection:** "In Docita, I built a healthcare SaaS with strict data isolation. The same multi-tenant patterns apply to pharmacy — each pharmacy location needs isolated inventory and order data."
- **Scaling:** "I've scaled PostgreSQL from 25 to handling concurrent bookings. At Redcare scale, I'd apply the same partitioning and connection pooling strategies."
- **Reliability:** "I designed an outbox pattern for healthcare notifications. The same pattern ensures order confirmations are never lost."

### Questions to Ask Them

1. "How do you handle medication interaction checking at scale?"
2. "What's your approach to A/B testing in a healthcare context?"
3. "How do you balance personalization with privacy in pharmacy recommendations?"

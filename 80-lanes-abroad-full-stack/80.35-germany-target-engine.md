## The Operating Loop (with career-ops)

Run this weekly from `~/repos/career-ops` — it's already configured with your portals, dedup ledger, and tracker:

```text
MON npm run scan # new postings → data/pipeline.md
TUE /career-ops pipeline # evaluate new URLs; score vs cv.md
     ≥4.0 → /career-ops pdf # regenerate tailored PDF (resume fixes are in!)
WED contacto pass # 5 DMs: pending apps first (LiveEO, Redcare, MVST,
                                  # Snke, Tanso), then Tier-1 (NavVis, Konux, DeepOpinion)
THU submit best-scored apps # n8n → Scalable-AI → SumUp (already evaluated!)
FRI follow-ups # Clera reply + any recruiter responses
SUN /career-ops stats # funnel review; update this file's status table
```

**Referral-first rule:** for every Tier-1/2 application, one DM before submitting — templates in the [outreach playbook](personal/outreach-playbook.md). Cold applications only for startups <50 people where founder-reads-everything odds are decent.

### DM skeleton that works (≤300 chars)

> Hi {name} — I'm a senior full-stack TS engineer (NestJS/React/PostgreSQL) shipping a multi-tenant healthcare SaaS. {Company}'s {specific product} is exactly the problem-space I work in. Applied for {role} on {date} — would love 15 min to see if my {specific overlap} could help your team.

Fill `{specific overlap}` from [80.32](80.32-company-prep-sheets.md): NavVis→PostGIS/data-layer depth · Snke→tenant isolation at hospital scale · MVST→studio breadth + AI guardrails · LiveEO→outbox/DLQ pipelines.

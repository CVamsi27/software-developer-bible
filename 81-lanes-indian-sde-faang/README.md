# SDE Interview Preparation Guide

Use the [lane index](INDEX.md) as the maintained reading flow. It connects assessment diagnosis, shared technical lessons, practice, role research, revision and mocks.

Start with the [complete guide](81.01-complete-guide.md) to establish the actual assessment and derive a solution. Record a representative attempt in the [progress tracker](81.08-progress-tracker.md), then select the next exercise through the [study plan](81.06-leetcode-study-plan.md). Use [category revision](REVISION.md) after learning and the [mock bank](81.09-mock-interview-question-bank.md) to test fresh work under the confirmed format.

Problem counts and preparation periods do not guarantee readiness. Check whether you can clarify the contract, implement correctly, test adverse cases and defend a decision when a constraint changes. Company guides are research starting points; confirm the process for the particular role.

Technical mechanisms live in the shared [study stacks](../INDEX.md). Use the [abroad full-stack lane](../80-lanes-abroad-full-stack/INDEX.md) for implementation-heavy preparation and relocation research. Personal resume versions and application records remain in the canonical private workspace.
